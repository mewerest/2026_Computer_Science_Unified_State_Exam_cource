🔀 Python: условные операторы

Часть 1. Проверка условий и знаки сравнения

Теория. Любое условие в программировании — это вопрос, на который можно ответить «да» или «нет». В Python ответ «да» — это специальное значение True (истина), а ответ «нет» — False (ложь). Вместе они называются булевым типом данных (bool).

Чтобы задать вопрос о сравнении двух величин, мы используем знаки сравнения — они очень похожи на математические, но есть важные отличия.

Знак Значение Пример условия Результат
== равно 5 == 5 True
!= не равно 5 != 3 True
> больше 7 > 4 True
< меньше 2 < 8 True
>= больше или равно 6 >= 6 True
<= меньше или равно 10 <= 9 False

⚠️ Внимание! Не путай = (оператор присваивания) и == (знак сравнения «равно»).

x = 5 — «положи в переменную x число 5».

x == 5 — «правда ли, что x равен 5?»

x = 10
y = 20

print("x равно y?", x == y)       # False
print("x не равно y?", x != y)    # True
print("x меньше y?", x < y)       # True
print("x больше или равно 10?", x >= 10)  # True

Часть 2. Условный оператор if — принимаем первое решение

Теория. Условный оператор if (с английского — «если») — это основа принятия решений в программировании. Он позволяет выполнить определённый блок кода только в том случае, если заданное условие истинно (True). Если условие ложно — код внутри блока просто пропускается.

Структура оператора if:

  • Ключевое слово if, после него — условие и двоеточие.
  • Со следующей строки — обязательный отступ в 4 пробела (или один Tab). Все строки с одинаковым отступом образуют тело условия.
  • Код без отступа — программа продолжается независимо от условия.
temperature = 25

if temperature > 20:
    print("На улице тепло, можно идти гулять!")
    print("Не забудь взять воду.")

print("Программа завершена.")  # Эта строка выполнится всегда

💡 Обрати внимание: если ввести temperature = 15 и запустить код, два сообщения внутри if не появятся. Программа просто пропустит этот блок и сразу напечатает «Программа завершена».

Часть 3. Конструкция else — план «Б»

Теория. Часто нам нужно не только выполнить действие, когда условие истинно, но и предусмотреть альтернативу на случай, если условие ложно. Для этого используется конструкция else (с английского — «иначе»).

else не имеет собственного условия — он срабатывает автоматически, когда условие в if оказалось ложным. Это как светофор: «если зелёный — иди, иначе — стой».

age = 16

if age >= 18:
    print("Доступ разрешён.")
    print("Добро пожаловать!")
else:
    print("Доступ запрещён.")
    print("Приходи через", 18 - age, "года/лет.")

print("Проверка завершена.")

Важное правило: else всегда пишется на том же уровне отступа, что и if, и после него тоже ставится двоеточие. Его тело точно так же выделяется отступом в 4 пробела.

Часть 4. Проверка нескольких условий: elif и вложенные проверки

Теория. В жизни редко бывает только два варианта. Для цепочек проверок в Python есть конструкция elif (сокращение от «else if» — «иначе если»).

Как это работает:

  • Python проверяет условия по порядку сверху вниз.
  • Как только находится первое истинное условие — выполняется его блок.
  • Все последующие elif и else игнорируются.
  • Если ни одно условие не истинно — срабатывает else (если он есть).
health = 65

if health >= 80:
    print("Герой полон сил!")
elif health >= 30:
    print("Герой ранен, но ещё в строю.")
elif health > 0:
    print("Герой при смерти! Нужно лечение.")
else:
    print("Герой пал в бою...")

print("Текущее здоровье:", health)

💡 Ключевой момент: в примере выше health = 65. Это удовлетворяет и второму (>= 30), и третьему (> 0) условию. Но выполнится только второй блок — тот, что встретился первым. Дальше проверка прекращается.

4.1 Вложенные условия

Теория. Иногда одного условия недостаточно, и решение зависит от комбинации факторов. В таких случаях можно поместить один if внутрь другого. Это называется вложенным условием. 

age = 20
has_ticket = True

if age >= 18:
    print("Возраст подходит.")
    # Это вложенная проверка — она выполняется, только если age >= 18
    if has_ticket == True:
        print("Билет есть. Проходи!")
    else:
        print("Билета нет. Купи на входе.")
else:
    print("Вход только с 18 лет.")

print("Охрана завершила проверку.")

Часть 5. Логические операторы: and, or, not

Теория. Часто нужно проверить не одно условие, а сразу несколько одновременно или в комбинации. Для этого существуют логические операторы. Они позволяют строить составные условия и делают код лаконичнее, чем вложенные if.

Оператор Значение Результат True, если… Пример
and логическое И оба условия истинны age >= 18 and has_ticket
or логическое ИЛИ хотя бы одно условие истинно day == "сб" or day == "вс"
not логическое НЕ условие ложно (переворачивает) not is_blocked 
# Пример с and — оба условия должны быть истинны
temperature = 22
is_sunny = True

if temperature > 20 and is_sunny == True:
    print("Идеальная погода для прогулки!")
else:
    print("Лучше остаться дома.")

# Пример с or — достаточно одного истинного условия
day = "суббота"
if day == "суббота" or day == "воскресенье":
    print("Ура, выходной!")
else:
    print("Сегодня рабочий день.")

# Пример с not — переворачивает значение
is_raining = False
if not is_raining:  # то же самое, что is_raining == False
    print("Зонт не нужен.")

💡 Лайфхак: можно комбинировать операторы и использовать скобки для группировки, как в математике:

if (age >= 18 and has_ticket) or is_vip: — «пустить, если есть 18 лет и билет, либо если вип-гость».
