🛠️ Python: подготовка к работе

Методичка ученика · Установка Python и среды разработки для программирования

Часть 1. Что нужно для программирования на Python

Для того чтобы писать и запускать программы на Python, на компьютере должны быть установлены две вещи:

  1. Интерпретатор Python — программа, которая выполняет код на языке Python.
  2. Среда разработки (IDE) — программа, в которой удобно писать код, запускать его и находить ошибки.

💡 Важное примечание для начала: интерпретатор Python и стандартная среда IDLE устанавливаются вместе. После этого можно по выбору установить одну из более продвинутых сред разработки: PyCharm или Wing IDE 101. На первое время достаточно IDLE — она уже есть сразу после установки Python.

Часть 2. Установка Python и IDLE

Шаг 1. Скачивание установщика

  1. Перейди на официальный сайт Python:
    python.org/downloads →
  2. Сайт автоматически предложит последнюю версию Python для твоей операционной системы.
  3. Нажми на жёлтую кнопку «Download Python 3.x.x» (где x.x — номер версии, например 3.12).
  4. Дождись окончания загрузки файла (обычно это занимает меньше минуты).

Шаг 2. Установка Python

  1. Запусти скачанный файл (двойным кликом).
  2. Обязательно поставь галочку ✅ «Add Python to PATH» в нижней части окна установщика. Это важно — без неё Python может не запуститься из командной строки.
  3. Нажми «Install Now».
  4. Дождись завершения установки. Появится окно «Setup was successful» — установка завершена.

Шаг 3. Первый запуск IDLE

IDLE — это стандартная среда разработки, которая устанавливается вместе с Python. Она простая, но для начала идеально подходит.

  1. Нажми клавишу Windows (или открой меню «Пуск»).
  2. Начни вводить слово «IDLE».
  3. В результатах поиска появится «IDLE (Python 3.x 64-bit)» — запусти его.
  4. Откроется окно с заголовком «Python Shell» — это интерактивная консоль. Знак >>> означает, что Python готов к работе.
  5. Попробуй написать print("Привет, мир!") и нажать Enter — ты увидишь результат.

Шаг 4. Создание первого файла в IDLE

  1. В окне IDLE выбери меню File → New File (или нажми Ctrl+N).
  2. Откроется новое окно — это редактор кода. Здесь можно писать программу из нескольких строк.
  3. Напиши простую программу: 
    print("Это моя первая программа!")
name = input("Как тебя зовут? ")
print("Привет,", name)
  4. Сохрани файл: File → Save (Ctrl+S), дай имя, например first_program.py.
  5. Запусти программу: Run → Run Module (F5).
  6. Результат выполнения появится в окне Python Shell.

Часть 3. Что такое IDE и зачем она нужна

IDE (Integrated Development Environment) — это интегрированная среда разработки. Простыми словами — программа-помощник для написания кода.

Что даёт IDE:

  • Подсветка синтаксиса — код раскрашивается, его легче читать.
  • Автодополнение — IDE подсказывает, какие команды доступны.
  • Подсказки об ошибках — выделяет строки с ошибками, часто ещё до запуска.
  • Удобный запуск — не нужно переключаться между редактором и консолью.
  • Отладчик — возможность выполнять программу по шагам, чтобы найти ошибку.

💡 Выбор IDE — это дело вкуса. Достаточно установить одну среду разработки, в которой тебе удобнее всего работать. Можно начать с IDLE (она уже есть), а позже перейти на PyCharm или Wing IDE. Ниже — инструкции по установке каждой из них.

Часть 4. Установка PyCharm Community Edition

PyCharm — одна из самых популярных профессиональных сред разработки для Python. Версия Community Edition — бесплатная и содержит всё необходимое для подготовки к ЕГЭ.

Шаг 1. Скачивание

  1. Перейди на официальный сайт JetBrains:
    jetbrains.com/pycharm/download →
  2. На странице две версии: Professional (платная) и Community (бесплатная).
  3. Нажми на кнопку «Download» под надписью «Community Edition».
  4. Дождись окончания загрузки.

Шаг 2. Установка

  1. Запусти скачанный установщик.
  2. Нажимай «Next», принимая настройки по умолчанию.
  3. На шаге «Installation Options» рекомендуется отметить:
    • ✅ Add "Open Folder as Project"
    • ✅ Add launchers dir to the PATH
  4. Нажми «Install» и дождись завершения.
  5. После установки выбери «Reboot now» (перезагрузка рекомендуется, но не обязательна).

Шаг 3. Первый запуск и создание проекта

  1. Запусти PyCharm (найди в меню «Пуск»).
  2. При первом запуске прими условия использования.
  3. Нажми «New Project».
  4. Укажи папку для проекта (например, C:\Users\ТвоёИмя\PycharmProjects\my_first_project).
  5. Убедись, что в поле «Interpreter» выбран установленный Python.
  6. Нажми «Create».
  7. В левой панели кликни правой кнопкой по папке проекта → New → Python File. Назови файл, например main.
  8. Напиши код и запусти его: зелёный треугольник ▶ в правом верхнем углу или Shift+F10.

Часть 5. Установка Wing IDE 101

Wing IDE 101 — простая и лёгкая среда разработки, специально ориентированная на начинающих. Хороший выбор, если не хочется разбираться в сложном интерфейсе PyCharm.

Шаг 1. Скачивание

  1. Перейди на официальный сайт Wingware:
    wingware.com/downloads →
  2. На странице три версии. Нас интересует «Wing IDE 101» — она бесплатная.
  3. Нажми на кнопку «Download» под Wing IDE 101.
  4. Выбери версию для своей операционной системы (Windows, macOS или Linux).
  5. Дождись окончания загрузки.

Шаг 2. Установка

  1. Запусти скачанный установщик.
  2. Следуй инструкциям установщика: принимай лицензионное соглашение, выбирай папку для установки (можно оставить по умолчанию).
  3. Нажимай «Next» до завершения установки.

Шаг 3. Первый запуск и создание файла

  1. Запусти Wing IDE 101 (найди в меню «Пуск»).
  2. При первом запуске может появиться окно с предложением настроить редактор — можно просто закрыть его или принять настройки по умолчанию.
  3. Напиши код в центральном окне редактора.
  4. Сохрани файл: File → Save, выбери папку и имя с расширением .py.
  5. Запусти программу: зелёная стрелка ▶ на панели инструментов или F5.
  6. Результат появится в нижнем окне «Shell».

Часть 6. Онлайн-платформы — программирование без установки

Если нет возможности установить Python на компьютер (например, работаешь с чужого устройства или возникли проблемы с установкой), можно использовать онлайн-платформы. Они работают прямо в браузере и не требуют установки.

Примеры онлайн-платформ для программирования на Python:

  • online-python.com — простой онлайн-редактор и интерпретатор Python. Заходишь на сайт, пишешь код, нажимаешь «Run» — и видишь результат.
  • Существуют и другие аналогичные сервисы: Replit, Google Colab, Programiz.

⚠️ Важное предупреждение: на ЕГЭ по информатике нет доступа к интернету, поэтому онлайн-платформы на экзамене недоступны. При подготовке обязательно научись работать в офлайн-среде (IDLE, PyCharm или Wing IDE) — именно она будет установлена на экзаменационном компьютере. Онлайн-платформы используй только как временное решение или для быстрой проверки идей.
