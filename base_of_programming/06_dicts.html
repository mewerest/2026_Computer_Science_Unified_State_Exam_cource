📖 Python: словари

Методичка ученика · Прочитай теорию, разбери примеры и выполняй домашние задания.

Часть 1. Что такое словарь и зачем он нужен

Теория. Список хранит элементы по порядку, и чтобы найти нужный, мы должны знать его индекс. Но часто данные удобнее хранить не по номеру, а по ключу — осмысленному имени.

Словарь (dict) — это коллекция пар «ключ → значение». Как настоящий словарь: ищешь слово (ключ) — получаешь его определение (значение). Ключи уникальны, значения могут повторяться.

Словарь: ключ → значение

"яблоко" → "фрукт"
"огурец" → "овощ"
"арбуз" → "ягода"
# Словарь — доступ по ключу
products = {
    "яблоко": "фрукт",
    "огурец": "овощ",
    "арбуз": "ягода"
}

print(products["огурец"])  # "овощ" — мгновенно

Часть 2. Создание словаря и базовые операции

Теория. Словарь создаётся с помощью фигурных скобок {}. Внутри — пары ключ: значение. Ключом может быть любой неизменяемый тип (строки, числа), значением — что угодно. 

# Создание словаря
student = {
    "имя": "Анна",
    "возраст": 17,
    "класс": 11,
    "средний_балл": 4.7
}

# Получение значения
print(student["имя"])       # Анна

# Добавление новой пары
student["город"] = "Москва"

# Изменение значения
student["возраст"] = 18

# Удаление пары
del student["класс"]

⚠️ Ошибка KeyError: если обратиться к несуществующему ключу — student["адрес"] — будет ошибка. Используй .get() для безопасного доступа.

Часть 3. Безопасный доступ — in и .get()

in — проверяет, есть ли ключ в словаре. Возвращает True или False.

.get() — безопасно получает значение по ключу. Если ключа нет — возвращает None или указанное значение по умолчанию.

Подробнее в справочнике →

student = {"имя": "Борис", "возраст": 17}

# Проверка наличия ключа
if "класс" in student:
    print(student["класс"])
else:
    print("Класс неизвестен")

# Безопасное получение через .get()
city = student.get("город", "не указан")
print("Город:", city)  # "не указан"

Часть 4. Перебор словаря — ключи, значения, пары

.keys() — возвращает все ключи словаря.

.values() — возвращает все значения словаря.

.items() — возвращает пары (ключ, значение). Самый популярный метод для перебора.

Все методы словарей в справочнике →

fruits = {"яблоко": 150, "банан": 90, "апельсин": 80, "киви": 60}

# Перебор ключей
for fruit in fruits:
    print(fruit)

# Перебор значений
for calories in fruits.values():
    print(calories, "ккал")

# Перебор пар — самый полезный
for name, cals in fruits.items():
    print(f"{name}: {cals} ккал")

Часть 5. Главный паттерн — подсчёт частоты

Теория. Самая частая задача на словари в ЕГЭ — подсчёт частоты: сколько раз каждый элемент встретился в наборе данных. Словарь идеально подходит: ключ — элемент, значение — счётчик.

# Подсчёт частоты слов
text = "яблоко банан яблоко апельсин банан яблоко киви банан банан"
words = text.split()

word_count = {}
for word in words:
    word_count[word] = word_count.get(word, 0) + 1

print("Частота слов:")
for word, count in word_count.items():
    print(f"  {word}: {count}")

# Самое частое слово
most_common = max(word_count, key=word_count.get)
print(f"Самое частое: '{most_common}' — {word_count[most_common]} раз(а)")

💡 Магия max(dict, key=dict.get): находит ключ с максимальным значением. key=dict.get говорит: «сравнивай не ключи, а значения, которые по этим ключам лежат».

Часть 6. Группировка данных

# Группировка учеников по классу
students = [("Анна", 10), ("Борис", 11), ("Виктор", 10),
            ("Галина", 11), ("Дмитрий", 10), ("Елена", 9)]

by_class = {}
for name, grade in students:
    if grade not in by_class:
        by_class[grade] = []
    by_class[grade].append(name)

for grade in sorted(by_class):
    print(f"{grade} класс: {', '.join(by_class[grade])}")
