⚙️ Python: функции

Методичка ученика · Прочитай теорию, разбери примеры — на занятии будем создавать собственные команды.

Часть 1. Введение в функции — зачем они нужны

Теория. Представь, что в программе нужно трижды посчитать площадь прямоугольника. Можно скопировать код три раза, но это дублирование. Если нужно будет исправить формулу — придётся править в трёх местах.

Функция — это именованный блок кода, который можно вызвать из любого места программы. Мы даём функции имя, описываем, что она делает, а затем используем это имя как команду.

Как работает функция:

Входные данные
(аргументы) → ФУНКЦИЯ
(блок кода) → Результат
(возвращаемое значение) 
# Без функций — дублирование кода
w1, h1 = 10, 5
area1 = w1 * h1
print("Площадь 1:", area1)

w2, h2 = 7, 3
area2 = w2 * h2
print("Площадь 2:", area2)

# Три одинаковых блока — а если формула изменится?

Часть 2. Создание и вызов функций

Теория. Функция создаётся с помощью ключевого слова def (от «define»). После def идёт имя функции, круглые скобки и двоеточие. Тело функции пишется с отступом в 4 пробела. Чтобы функция выполнилась, её нужно вызвать.

def — ключевое слово для создания функции. После него: имя, круглые скобки с параметрами, двоеточие.

Подробнее в справочнике →

# Определяем функцию
def greet():
    print("Привет!")
    print("Добро пожаловать!")
    print("—" * 30)

# Вызываем функцию
greet()
greet()  # Можно сколько угодно раз

⚠️ Важно: функция должна быть определена до её вызова. Если вызвать greet() до def greet(): — ошибка NameError.

Часть 3. Параметры — передаём данные в функцию

Теория. Чтобы функция была гибкой, ей можно передавать параметры — значения, с которыми она будет работать. Параметры перечисляются в скобках при определении функции. При вызове мы передаём аргументы — конкретные значения.

# Функция с одним параметром
def greet_person(name):
    print(f"Привет, {name}!")

greet_person("Анна")
greet_person("Борис")

# Функция с несколькими параметрами
def print_area(width, height):
    area = width * height
    print(f"{width}×{height} = {area}")

print_area(10, 5)
print_area(7, 3)

Часть 4. Возврат значения — оператор return

return — завершает функцию и возвращает указанное значение в место вызова. Без return функция возвращает None.

Подробнее в справочнике →

# Функция с return — возвращает результат
def calculate_area(width, height):
    area = width * height
    return area

# Сохраняем результат в переменную
area1 = calculate_area(10, 5)
area2 = calculate_area(7, 3)
print(f"Сумма площадей: {area1 + area2}")
# return немедленно завершает функцию
def can_drive(age):
    if age >= 18:
        return "Можно водить"

print(can_drive(20))

4.1 Возврат нескольких значений

# Функция возвращает сразу несколько значений
def rectangle_info(width, height):
    area = width * height
    perimeter = 2 * (width + height)
    return area, perimeter

rect_area, rect_perim = rectangle_info(10, 5)
print(f"Площадь: {rect_area}, Периметр: {rect_perim}")

Часть 5. Область видимости переменных

Теория. Переменные, созданные внутри функции, — локальные, они «живут» только внутри этой функции. Переменные вне функций — глобальные. Функция — это «чёрный ящик», который работает со своими данными.

global_var = "Я глобальная"

def demo_scope():
    local_var = "Я локальная"
    print("Внутри:", global_var)    # Глобальную видно
    print("Внутри:", local_var)     # Локальную видно

demo_scope()
print("Снаружи:", global_var)    # Глобальную видно
# print(local_var)  # ОШИБКА! Локальная переменная не видна снаружи

⚠️ Изменять глобальные переменные внутри функции — плохая практика. Функция должна получать данные через параметры и возвращать результат через return.

Часть 6. Пустые функции — заглушки pass

pass — пустая операция-заглушка. Используется там, где синтаксис требует кода, но по логике там пока ничего нет.

Подробнее в справочнике →

# Пустые функции-заглушки — программа не падает
def start_game():
    pass  # Реализую позже

def load_level(number):
    pass  # Реализую позже

def save_progress():
    pass  # Реализую позже

# Программа запускается, хотя функции пока ничего не делают
print("Игровой движок загружен.")
start_game()
print("Игра завершена (пока что мгновенно).")

💡 Пошаговая разработка: сначала создаёшь структуру программы из заглушек — программа уже работает. Потом постепенно заменяешь pass на реальный код. Это стандартный подход в программировании.
