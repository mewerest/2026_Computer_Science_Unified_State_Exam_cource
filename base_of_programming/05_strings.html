🔤 Python: строки

Методичка ученика · Прочитай теорию, разбери примеры — на занятии будем виртуозно владеть текстом.

Часть 1. Строки как последовательности символов

Теория. Мы уже знаем, что строка (str) — это тип данных для хранения текста. Но строка в Python — это не просто «кусок текста», а упорядоченная последовательность символов, где каждый символ имеет свой индекс. Как и в списках, индексация начинается с нуля.

Это значит, что к строке можно применять многие операции, знакомые нам по спискам: узнавать длину через len(), обращаться к отдельным символам по индексу, использовать отрицательные индексы.

word = "Python"

print("Строка:", word)
print("Длина:", len(word))   # 6

# Доступ к отдельным символам
print(word[0])    # P
print(word[-1])   # n
print(word[-2])   # o

⚠️ Важное отличие строк от списков: строки в Python неизменяемы. Нельзя заменить один символ: word[0] = "J" вызовет ошибку. Чтобы «изменить» строку, нужно создать новую.

Часть 2. Срезы строк

Теория. Срез (slice) — это механизм, позволяющий извлечь часть строки. Синтаксис точно такой же, как у срезов списков: строка[начало:конец:шаг]. Символ с индексом конец не включается.

Строка:     P y t h o n
Индексы (+):   0 1 2 3 4 5
Индексы (−):   −6 −5 −4 −3 −2 −1 
text = "программирование"

# Базовые срезы
print(text[:7])      # програм
print(text[7:])      # мирование
print(text[-7:])     # рование (последние 7 символов)

# Срезы с шагом
print(text[::2])      # каждый второй символ

# Знаменитый трюк — переворот строки
print(text[::-1])     # еинавориммаргорп
# Проверка на палиндром — применение переворота
word = "казак"
if word == word[::-1]:
    print(f"'{word}' — палиндром!")
else:
    print(f"'{word}' — не палиндром.")

Часть 3. Методы строк

Теория. У строк есть множество встроенных методов — готовых функций, которые выполняют полезные операции. Поскольку строки неизменяемы, методы не меняют исходную строку, а возвращают новую.

.upper() — все буквы заглавные. .lower() — все строчные.

.strip() — убирает пробелы и переносы строк по краям.

.replace() — заменяет подстроку на другую.

.find() — ищет подстроку, возвращает индекс или −1. .count() — считает вхождения.

Все методы строк в справочнике →

text = "  Привет, Python! Python — это круто.  "

clean = text.strip()
print("После strip:", clean)

print("upper:", clean.upper())
print("lower:", clean.lower())

replaced = clean.replace("Python", "Кот")
print("replace:", replaced)

print("find:", clean.find("Python"))
print("count:", clean.count("Python"))

Часть 4. split() и join() — разборка и сборка строк

.split() — разбивает строку по разделителю и возвращает список подстрок. Без аргумента — разбивает по пробелам.

.join() — собирает список строк в одну, вставляя разделитель между элементами. Обратная операция к .split().

Подробнее в справочнике →

# split() — разбиение на слова
sentence = "Python — отличный язык программирования"
words = sentence.split()
print("Слова:", words)
print("Количество слов:", len(words))

# split() с разделителем
data = "Анна,25,Москва"
parts = data.split(",")
print("Части:", parts)  # ['Анна', '25', 'Москва']

# join() — склеивание списка в строку
fruits = ["яблоко", "банан", "апельсин"]
result = ", ".join(fruits)
print(result)  # "яблоко, банан, апельсин"

Часть 5. Преобразование типов данных

Теория. В программировании постоянно нужно преобразовывать данные из одного типа в другой. Особенно это важно при работе со строками: данные из файла или пользовательского ввода всегда приходят строками, и их нужно превращать в числа.

int() — преобразует строку в целое число. float() — в число с плавающей точкой.

str() — преобразует любой объект в строку. list() — создаёт список из итерируемого объекта.

Подробнее в справочнике →

# Строку в число
num_str = "123"
num = int(num_str)
print(num + 7)  # 130

# Число в строку
age = 16
print("Мне " + str(age) + " лет")

# Строку в список символов
chars = list("Python")
print(chars)  # ['P', 'y', 't', 'h', 'o', 'n']

💡 Обработка ошибок при преобразовании: не каждая строка может стать числом. Используй .isdigit() для проверки, состоит ли строка только из цифр, или конструкцию try...except для безопасного преобразования.
