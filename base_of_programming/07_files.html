📂 Python: чтение файлов

Методичка ученика · Прочитай теорию, разбери примеры — на занятии будем учиться работать с данными из файлов.

Часть 1. Открытие и чтение файла

Теория. До сих пор мы хранили данные прямо в коде. Но в реальных программах информация чаще всего находится в файлах. Python умеет читать файлы с диска — для этого есть встроенная функция open().

open() — открывает файл и возвращает файловый объект. Параметры: путь к файлу, режим ('r' — чтение), кодировка (encoding="utf-8").

with ... as — конструкция для безопасной работы с файлами. Гарантирует, что файл будет закрыт автоматически.

Подробнее в справочнике →

# Открываем файл и читаем его целиком
with open("hello.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)

# После выхода из блока with файл уже закрыт
print("Файл автоматически закрыт.")
Привет, мир! Это мой первый файл. Python — это круто!

⚠️ Важно: encoding="utf-8" — указывает кодировку. UTF-8 поддерживает русские буквы. Без этого параметра на Windows кириллица может отображаться некорректно.

Часть 2. Методы чтения файла

.read() — читает весь файл одной строкой.

.readline() — читает одну строку (до \n). При следующем вызове — следующую.

.readlines() — читает все строки и возвращает список строк.

Все методы файлов в справочнике →

# readlines() — читаем все строки списком
with open("fruits.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

print("Список строк:", lines)

Часть 3. Перебор файла в цикле for

Теория. Файловый объект можно перебирать в цикле for — на каждой итерации будет получаться очередная строка. Это самый элегантный и популярный способ построчной обработки.

# Построчный перебор — самый удобный способ
with open("fruits.txt", "r", encoding="utf-8") as file:
    for line in file:
        clean = line.strip()
        if clean:  # Пропускаем пустые строки
            print("Фрукт:", clean)

Часть 4. Заполнение списка данными из файла

# Читаем список учеников из файла в список
students = []
with open("students.txt", "r", encoding="utf-8") as file:
    for line in file:
        name = line.strip()
        if name:
            students.append(name)

print("Список учеников:", students)
print("Всего:", len(students))

4.1 Обработка числовых данных из файла

# Читаем баллы и считаем статистику
scores = []
with open("scores.txt", "r", encoding="utf-8") as file:
    for line in file:
        line = line.strip()
        if line:
            scores.append(int(line))

print("Баллы:", scores)
print("Максимум:", max(scores))
print("Средний:", sum(scores) / len(scores))

Часть 5. Обработка CSV-подобных файлов

Теория. Часто данные структурированы: каждая строка содержит несколько значений, разделённых запятой. Это называется CSV (Comma-Separated Values). Разбираем такие строки с помощью уже знакомого метода .split().

# Файл users.txt: имя,возраст,город
with open("users.txt", "r", encoding="utf-8") as file:
    for line in file:
        line = line.strip()
        if line:
            parts = line.split(",")
            name = parts[0]
            age = int(parts[1])
            city = parts[2]
            print(f"{name} живёт в {city}, возраст — {age}")

Часть 6. Обработка ошибок при чтении

try...except — конструкция для обработки ошибок. Код в try выполняется; если возникает ошибка — выполняется except. Программа не падает.

Подробнее в справочнике →

filename = "missing_file.txt"
try:
    with open(filename, "r", encoding="utf-8") as file:
        content = file.read()
        print(content)
except FileNotFoundError:
    print(f"Файл '{filename}' не найден.")
