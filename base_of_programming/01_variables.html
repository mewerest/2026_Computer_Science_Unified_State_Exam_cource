Часть 1. «Привет, мир!» — вывод на экран

Теория. Программа — это набор инструкций. Чтобы увидеть результат работы программы, мы используем функцию, которая выводит данные на экран. В Python она называется print(). Всё, что мы помещаем внутрь скобок, отображается в консоли.

Текст обязательно пишется в кавычках (одинарных или двойных). Числа можно передавать без кавычек.

print() — выводит переданные объекты на экран. Можно передавать сколько угодно объектов через запятую.

Подробнее в справочнике →

print("Привет, мир!")
print('Я учу Python')
print(2024)  # Числа можно выводить без кавычек

💡 Комментарии в коде: всё, что идёт после символа # — это комментарий. Python игнорирует комментарии, они нужны для пояснений. Пиши комментарии, чтобы не забыть, что делает твой код.

Часть 2. Переменные — именованные «коробки» для данных

Теория. Компьютер постоянно работает с данными. Чтобы было удобно к ним обращаться, мы даём данным имена — создаём переменные. Представь, что переменная — это коробка с наклейкой: на коробке написано имя, а внутри лежит значение.

Знак = в Python — это не математическое «равно», а оператор присваивания. Он говорит: «положи в переменную слева значение, которое находится справа». Сначала вычисляется правая часть, затем результат кладётся в переменную.

# Создаём переменные
name = "Алиса"        # Переменная name хранит строку "Алиса"
age = 16              # Переменная age хранит число 16
height = 1.68         # Переменная height хранит число 1.68

# Выводим значения переменных
print(name)
print(age)
print(height)

Часть 3. Базовые типы данных

Теория. Данные в Python бывают разных типов. Тип определяет, какие операции можно выполнять с данными. Три главных типа для старта:

  • Целые числа (int) — 5, 100, -3
  • Числа с плавающей точкой (float) — 3.14, -0.5, 2.0
  • Строки (str) — любой текст: "Hello", "123" (это уже не число, а строка символов!)

type() — возвращает тип переданного объекта. Полезно, чтобы убедиться, с каким именно типом мы работаем.

Подробнее в справочнике →

name = "Алиса"
age = 16
height = 1.68

# Узнаем типы данных с помощью type()
print(type(name))    # <class 'str'>
print(type(age))     # <class 'int'>
print(type(height))  # <class 'float'>

Часть 4. Арифметические операции

Теория. Python отлично считает. Все действия выполняются с помощью специальных знаков — операторов. Результат операции зависит от того, какой оператор мы выбрали, и от типов чисел, которые в ней участвуют.

Оператор Действие Пример Результат
+ Сложение 5 + 3 8
- Вычитание 10 - 4 6
* Умножение 6 * 7 42
** Возведение в степень 2 ** 10 1024
/ Обычное деление 15 / 4 3.75
// Целочисленное деление 15 // 4 3
% Остаток от деления 15 % 4 3

⚠️ Ключевое различие: / всегда возвращает float. // отбрасывает дробную часть. % показывает, сколько «лишнего» остаётся, когда одно число не делится на другое нацело.

a = 15
b = 4

print("Сложение:", a + b)        # 19
print("Умножение:", a * b)        # 60
print("Степень:", 2 ** 3)          # 8
print("Корень из 9:", 9 ** 0.5)    # 3.0 (степень 0.5 — квадратный корень)

# Три вида деления — самая важная тема урока!
print("Обычное деление:", a / b)     # 3.75 (результат всегда float)
print("Целочисленное:", a // b)      # 3 (отбрасывает дробную часть)
print("Остаток:", a % b)            # 3 (15 = 4×3 + 3)

💡 Приоритет операций: как в математике — сначала скобки, потом степень **, потом умножение/деление, потом сложение/вычитание. Если сомневаешься — ставь скобки: (2 + 3) * 4.

Часть 5. Изменение значений переменных

Теория. Значение, которое лежит в «коробке»-переменной, можно заменить в любой момент. Старое значение при этом забывается. Более того, чтобы вычислить новое значение, мы можем использовать текущее значение этой же переменной — это абсолютно нормально и очень удобно.

В Python есть короткая форма записи таких изменений: +=, -=, *= и другие. Это называется «синтаксический сахар» — более короткий и приятный способ написать то же самое.

xp = 100
print("Начальный опыт:", xp)

# Полностью заменили значение
xp = 200
print("Новый опыт:", xp)

# Увеличили на 50 (взяли старое значение и прибавили)
xp = xp + 50
print("После апа:", xp)  # Будет 250

# Короткая запись (синтаксический сахар)
xp += 10     # то же самое, что xp = xp + 10
print("Ещё плюс 10:", xp)  # Будет 260

xp -= 30     # то же самое, что xp = xp - 30
xp *= 2      # то же самое, что xp = xp * 2
print("Итоговый опыт:", xp)
