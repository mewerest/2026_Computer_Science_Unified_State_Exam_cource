Часть 1. Введение в циклы — зачем они нужны

Теория. Представь, что тебе нужно вывести числа от 1 до 100. Писать сто строк с print() — это долго и скучно. А если нужно вывести числа до миллиона? Вот тут на помощь приходят циклы.

Цикл — это конструкция, которая позволяет выполнить один и тот же блок кода много раз. Вместо копирования строк мы описываем правило один раз, а компьютер повторяет его столько, сколько нужно.

В Python два основных вида циклов:

  • Цикл for — используется, когда мы заранее знаем, сколько повторений нужно, или когда нужно перебрать элементы коллекции (списка, строки и т.д.).
  • Цикл while — используется, когда количество повторений заранее неизвестно и зависит от условия. Он повторяется, пока условие остаётся истинным.

Часть 2. Структура цикла for

Теория. Цикл for последовательно перебирает элементы коллекции. На каждом шаге он берёт очередной элемент, присваивает его переменной и выполняет тело цикла. Когда элементы заканчиваются — цикл завершается.

Структура:

  • Ключевое слово for.
  • Имя переменной (придумываем сами).
  • Ключевое слово in.
  • Коллекция (список, строка, диапазон).
  • Двоеточие.
  • Тело цикла с отступом в 4 пробела.
# Цикл for по списку — перебираем элементы
fruits = ["яблоко", "банан", "апельсин"]

for fruit in fruits:
    print("Сейчас обрабатывается:", fruit)
    print("Я люблю этот фрукт!")

print("Цикл завершён.")  # Без отступа — выполнится один раз после цикла
# Цикл for по строке — перебираем символы
word = "Python"

for letter in word:
    print("Буква:", letter)

Часть 3. Функция range() — числовые последовательности

Теория. Чтобы выполнить цикл определённое количество раз, не создавая список вручную, используют функцию range(). Она генерирует последовательность чисел «на лету», не занимая лишнюю память.

range() — генерирует последовательность целых чисел. Число конец никогда не включается. Может принимать от 1 до 3 аргументов.

Подробнее в справочнике →

Форма Значение Пример Результат
range(конец) От 0 до конец-1 range(5) 0, 1, 2, 3, 4
range(начало, конец) От начало до конец-1 range(2, 6) 2, 3, 4, 5
range(начало, конец, шаг) От начало до конец-1 с шагом range(1, 10, 2) 1, 3, 5, 7, 9

⚠️ Ключевое правило: число конец никогда не включается в результат. range(5) — это числа 0, 1, 2, 3, 4 (пять чисел, но пятый индекс не включается).

# range(конец) — от 0 до 4
print("range(5):")
for i in range(5):
    print(i)                            # 0, 1, 2, 3, 4

# range(начало, конец) — от 3 до 7
print("\nrange(3, 8):")
for i in range(3, 8):
    print(i)                            # 3, 4, 5, 6, 7

# range(начало, конец, шаг) — от 0 до 9 с шагом 2
print("\nrange(0, 10, 2):")
for i in range(0, 10, 2):
    print(i)                            # 0, 2, 4, 6, 8

# Обратный отсчёт — шаг -1
print("\nОбратный отсчёт:")
for i in range(5, 0, -1):
    print(i)                            # 5, 4, 3, 2, 1

💡 Перебор индексов: for i in range(len(список)) — перебирает индексы от 0 до длины-1. Полезно, когда нужно знать позицию элемента или изменить его.

Часть 4. Цикл while — повторяем, пока условие истинно

Теория. Цикл while (с английского — «пока») выполняет блок кода до тех пор, пока условие остаётся истинным (True). Как только условие становится ложным — цикл останавливается.

Цикл while удобен, когда мы не знаем заранее, сколько именно шагов потребуется: например, запрашиваем пароль у пользователя, пока он не введёт правильный, или ждём определённого события в игре.

# Простой счётчик с while
counter = 1

while counter <= 5:
    print("Шаг номер", counter)
    counter += 1                  # Увеличиваем счётчик — важно!

print("Цикл завершён. counter =", counter)
# Пример — считаем сумму цифр числа
number = 12345
sum_digits = 0

while number > 0:
    digit = number % 10            # Получаем последнюю цифру
    sum_digits += digit            # Добавляем к сумме
    number = number // 10          # Отбрасываем последнюю цифру

print("Сумма цифр:", sum_digits)   # 15

⚠️ Осторожно — бесконечный цикл! Если условие в while никогда не станет ложным, цикл будет выполняться бесконечно, и программа зависнет. Например: while True: print("Бесконечность..."). Всегда проверяй, что внутри цикла есть код, который в какой-то момент изменит условие на False.

Часть 5. Прерывание цикла — break и continue

Теория. Иногда нужно не просто дождаться конца цикла, а прервать его досрочно или пропустить отдельные итерации. Для этого есть два оператора:

break — немедленно прерывает выполнение цикла. Программа выходит из цикла и продолжает выполнение с первой строки после него.

continue — пропускает оставшуюся часть текущей итерации и переходит к следующей. Цикл не прерывается полностью.

Подробнее в справочнике →

# break — ищем первое отрицательное число и останавливаемся
numbers = [5, 8, 12, -3, 7, 9, -1, 4]

for num in numbers:
    if num < 0:
        print("Нашёл отрицательное число:", num)
        break                       # Выходим из цикла
    print("Проверил:", num)

print("Поиск завершён.")
# continue — пропускаем все отрицательные числа
numbers = [5, -2, 8, -7, 12, -3, 9]

for num in numbers:
    if num < 0:
        print("Пропускаю отрицательное:", num)
        continue                    # Переходим к следующему числу
    print("Обрабатываю:", num * 2)  # Выполнится только для положительных

Часть 6. Проверка нескольких условий в цикле

Теория. Внутри цикла можно использовать любые конструкции: условные операторы, вложенные циклы, логические операторы. Это позволяет строить сложную логику обработки данных.

# Классифицируем числа из списка
numbers = [10, -5, 0, 23, -18, 7, 0, 42, -3]
positive = 0
negative = 0
zero = 0

for num in numbers:
    if num > 0:
        positive += 1
    elif num < 0:
        negative += 1
    else:
        zero += 1

print(f"Положительных: {positive}, отрицательных: {negative}, нулей: {zero}")
# Поиск с несколькими условиями
numbers = [13, 27, 48, 55, 62, 71, 84]

for num in numbers:
    if num > 50 and num % 2 == 0:   # Больше 50 И чётное
        print("Нашёл подходящее число:", num)
        break
    print(num, "не подходит")
# Совмещение while и нескольких условий — игровая механика
health = 100
hit_count = 0

while health > 0:
    hit_count += 1
    if hit_count % 3 == 0:       # Каждый третий удар — критический
        damage = 30
        print(f"Удар {hit_count}: КРИТИЧЕСКИЙ! -{damage} HP")
    else:
        damage = 10
        print(f"Удар {hit_count}: обычный. -{damage} HP")
    health -= damage
    print(f"Осталось здоровья: {health}")

print(f"\nГерой продержался {hit_count} ударов.")
