📋 Python: списки

Методичка ученика · Прочитай теорию, разбери примеры — на занятии будем управлять коллекциями данных.

Часть 1. Введение в списки — что это и зачем

Теория. До сих пор мы хранили в переменных одно значение: одно число, одну строку. Но в реальных программах почти всегда нужно работать с наборами данных: списком учеников, набором оценок, перечнем товаров в корзине.

Список (list) — это упорядоченная коллекция элементов. Представь пронумерованные ячейки, в каждой из которых может лежать что угодно: числа, строки, даже другие списки. Список создаётся с помощью квадратных скобок [], а элементы внутри разделяются запятыми.

# Создаём списки
empty_list = []                          # Пустой список
fruits = ["яблоко", "банан", "апельсин", "киви"]
numbers = [10, 20, 30, 40, 50]
mixed = ["текст", 42, 3.14, True]        # В одном списке могут быть разные типы

print(fruits)
print(numbers)

Часть 2. Индексация — как добраться до элемента

Теория. У каждого элемента в списке есть свой номер — индекс. Индексация в Python начинается с нуля: первый элемент имеет индекс 0, второй — 1, и так далее. Чтобы получить элемент, пишем имя списка и индекс в квадратных скобках.

fruits = ["яблоко", "банан", "апельсин", "киви"]

print(fruits[0])   # яблоко
print(fruits[1])   # банан
print(fruits[-1])  # киви (отрицательный индекс — с конца)
print(fruits[-2])  # апельсин

⚠️ Ошибка новичка: если запросить индекс, которого в списке нет (например, fruits[4] в списке из четырёх элементов), Python выдаст ошибку IndexError: list index out of range.

Часть 3. Срезы — получаем часть списка

Теория. Срез (slice) позволяет получить сразу несколько элементов. Синтаксис: список[начало:конец]. Элемент с индексом конец не включается. Можно также указать шаг: список[начало:конец:шаг].

numbers = [10, 20, 30, 40, 50, 60]

print(numbers[0:3])   # [10, 20, 30] — индексы 0,1,2
print(numbers[:4])    # [10, 20, 30, 40] — от начала до индекса 3
print(numbers[3:])    # [40, 50, 60] — от индекса 3 до конца
print(numbers[::2])   # [10, 30, 50] — каждый второй
print(numbers[::-1])  # [60, 50, 40, 30, 20, 10] — переворот

Часть 4. Изменение элементов и основные методы

Теория. Списки в Python изменяемы — можно заменить элемент по индексу. Также у списков есть встроенные методы — функции, которые вызываются через точку.

.append() — добавляет элемент в конец списка.

.insert() — вставляет элемент на указанную позицию по индексу.

.remove() — удаляет первое вхождение указанного значения.

.pop() — удаляет элемент по индексу и возвращает его. Без индекса — удаляет последний.

Все методы списков в справочнике →

heroes = ["Человек-паук", "Бэтмен"]
print("Исходный:", heroes)

# .append() — добавление в конец
heroes.append("Супермен")
print("После append:", heroes)

# .insert() — вставка на позицию
heroes.insert(1, "Чудо-женщина")
print("После insert:", heroes)

# Изменение по индексу
heroes[2] = "Флэш"
print("После замены:", heroes)

# .remove() — удаление по значению
heroes.remove("Супермен")
print("После remove:", heroes)

# .pop() — удаление по индексу
removed = heroes.pop(1)
print("Удалён:", removed)
print("После pop:", heroes)

Часть 5. Полезные функции и сортировка

len() — возвращает количество элементов в списке.

min() и max() — возвращают минимальный и максимальный элемент.

sum() — возвращает сумму всех элементов (только для чисел).

Все встроенные функции в справочнике →

scores = [85, 92, 78, 95, 88]

print("Длина:", len(scores))
print("Мин:", min(scores))
print("Макс:", max(scores))
print("Сумма:", sum(scores))
print("Среднее:", sum(scores) / len(scores))

sorted() — возвращает новый отсортированный список, не меняя исходный.

.sort() — сортирует список на месте (изменяет его). reverse=True — по убыванию.

Подробнее в справочнике →

nums = [5, 2, 9, 1, 5, 6]

# sorted() — не меняет исходный
sorted_nums = sorted(nums)
print("Исходный:", nums)
print("Новый отсорт.:", sorted_nums)

# .sort() — меняет исходный
nums.sort()
print("После sort():", nums)

nums.sort(reverse=True)
print("По убыванию:", nums)

Часть 6. Циклы и списки

Теория. Списки и циклы — идеальная пара. Мы уже умеем перебирать список в цикле for. Теперь научимся формировать новые списки в цикле.

# Заполнение списка в цикле
squares = []                     # Пустой список
for i in range(1, 11):
    squares.append(i ** 2)

print("Квадраты:", squares)
# Формируем список только из чётных чисел
numbers = [3, 8, 1, 6, 12, 9, 4, 7]
even_numbers = []

for num in numbers:
    if num % 2 == 0:
        even_numbers.append(num)

print("Чётные:", even_numbers)
