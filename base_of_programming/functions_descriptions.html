🔧 Встроенные функции

print()

print(*объекты, sep=" ", end="\n")
Выводит переданные объекты на экран (в консоль). sep — разделитель между объектами, end — что вывести в конце.
print("Привет,", "мир!") # Привет, мир! print("Без переноса", end="") # не переводит строку

type()

type(объект)
Возвращает тип переданного объекта. Полезно для отладки и проверки, с каким типом данных мы работаем.
type(42) # <class 'int'> type("abc") # <class 'str'> type([1,2,3]) # <class 'list'>

len()

len(коллекция)
Возвращает длину (количество элементов) коллекции: строки, списка, словаря, кортежа, множества.
len("Python") # 6 len([1,2,3]) # 3 len({"a": 1}) # 1

range()

range(конец)
range(начало, конец)
range(начало, конец, шаг)
Генерирует последовательность целых чисел. Используется в циклах for. Число конец не включается в последовательность.
range(5) # 0, 1, 2, 3, 4 range(2, 6) # 2, 3, 4, 5 range(0, 10, 2) # 0, 2, 4, 6, 8 range(5, 0, -1) # 5, 4, 3, 2, 1

int()

int(строка_или_число)
Преобразует строку или число с плавающей точкой в целое число. Если строка содержит нечисловые символы — ошибка ValueError.
int("42") # 42 int(3.14) # 3 int("101", 2) # 5 (двоичная система)
См. также: float(), str()

float()

float(строка_или_число)
Преобразует строку или целое число в число с плавающей точкой.
float("3.14") # 3.14 float(5) # 5.0
См. также: int(), str()

str()

str(объект)
Преобразует любой объект в строковое представление. Необходимо, когда нужно объединить число с текстом.
str(42) # "42" str(3.14) # "3.14" str([1,2,3]) # "[1, 2, 3]"
См. также: int(), float()

bool()

bool(значение)
Преобразует значение в логический тип True или False. «Пустые» значения (0, "", [], {}) дают False.
bool(1) # True bool(0) # False bool("") # False bool([1,2]) # True

min()

min(коллекция)
Возвращает минимальный элемент коллекции (списка, строки, словаря — по ключам).
min([5, 2, 9, 1]) # 1 min("python") # 'h'
См. также: max(), sum()

max()

max(коллекция)
max(коллекция, key=функция)
Возвращает максимальный элемент коллекции. С аргументом key можно сравнивать по определённому признаку (например, max(dict, key=dict.get) — ключ с максимальным значением).
max([5, 2, 9, 1]) # 9 max(d, key=d.get) # ключ с макс. значением
См. также: min(), sum()

sum()

sum(коллекция_чисел, начальное=0)
Возвращает сумму всех элементов коллекции. Работает только с числами. Можно указать начальное значение вторым аргументом.
sum([1, 2, 3, 4, 5]) # 15 sum([1, 2, 3], 10) # 16
См. также: min(), max()

sorted()

sorted(коллекция, reverse=False)
Возвращает новый отсортированный список из элементов коллекции. Исходная коллекция не изменяется. reverse=True — по убыванию.
sorted([3, 1, 2]) # [1, 2, 3] sorted([3, 1, 2], reverse=True) # [3, 2, 1]
См. также: .sort()

list()

list(итерируемый_объект)
Создаёт список из переданного итерируемого объекта (строки, range, другого списка).
list("abc") # ['a', 'b', 'c'] list(range(3)) # [0, 1, 2]

dict()

dict() или dict(ключ=значение, ...)
Создаёт словарь. Может создавать пустой словарь или из именованных аргументов.
dict() # {} dict(x=1, y=2) # {'x': 1, 'y': 2} dict([("a", 1), ("b", 2)]) # {'a': 1, 'b': 2}

open()

open(путь, режим, encoding="utf-8")
Открывает файл и возвращает файловый объект для чтения или записи. Режимы: 'r' — чтение, 'w' — запись, 'a' — добавление. Рекомендуется использовать с with.
with open("file.txt", "r", encoding="utf-8") as f: text = f.read()
См. также: with

input()

input(подсказка)
Запрашивает у пользователя ввод с клавиатуры и возвращает введённую строку. Необязательный аргумент — текст-подсказка.
name = input("Введите имя: ") age = int(input("Введите возраст: "))

📝 Методы строк

.strip()

строка.strip()
Удаляет пробельные символы (пробелы, табуляции, переносы строк) в начале и в конце строки. Исходная строка не изменяется.
" привет ".strip() # "привет" " текст\n".strip() # "текст"

.split()

строка.split(разделитель)
Разбивает строку по указанному разделителю и возвращает список подстрок. Если разделитель не указан — разбивает по пробельным символам.
"a,b,c".split(",") # ['a', 'b', 'c'] "один два три".split() # ['один', 'два', 'три']
См. также: .join()

.join()

разделитель.join(список_строк)
Собирает список строк в одну строку, вставляя между элементами указанный разделитель. Обратная операция к .split().
", ".join(["a", "b", "c"]) # "a, b, c" "".join(['P', 'y']) # "Py"
См. также: .split()

.upper()

строка.upper()
Возвращает новую строку, в которой все буквы преобразованы в заглавные.
"привет".upper() # "ПРИВЕТ" "Python".upper() # "PYTHON"
См. также: .lower()

.lower()

строка.lower()
Возвращает новую строку, в которой все буквы преобразованы в строчные.
"ПРИВЕТ".lower() # "привет" "Python".lower() # "python"
См. также: .upper()

.replace()

строка.replace(старое, новое, количество)
Заменяет все вхождения подстроки старое на новое. Необязательный третий аргумент ограничивает количество замен.
"мама".replace("м", "п") # "папа" "аааа".replace("а", "б", 2) # "ббаа"

.find()

строка.find(подстрока, начало=0, конец=len)
Ищет подстроку в строке и возвращает индекс первого вхождения. Если подстрока не найдена — возвращает -1.
"Python".find("th") # 2 "Python".find("x") # -1

.count()

строка.count(подстрока)
Подсчитывает, сколько раз подстрока встречается в строке (непересекающиеся вхождения).
"бананан".count("на") # 2 "ааа".count("аа") # 1

.startswith()

строка.startswith(префикс)
Проверяет, начинается ли строка с указанного префикса. Возвращает True или False.
"Python".startswith("Py") # True "Python".startswith("Ja") # False
См. также: .endswith()

.endswith()

строка.endswith(суффикс)
Проверяет, заканчивается ли строка указанным суффиксом. Возвращает True или False.
"file.txt".endswith(".txt") # True "file.txt".endswith(".py") # False
См. также: .startswith()

.capitalize()

строка.capitalize()
Возвращает строку, в которой первый символ — заглавная буква, а остальные — строчные.
"пИтОН".capitalize() # "Питон"

.title()

строка.title()
Возвращает строку, в которой каждое слово начинается с заглавной буквы.
"привет мир".title() # "Привет Мир"

.isdigit()

строка.isdigit()
Проверяет, состоит ли строка только из цифр. Возвращает True или False.
"12345".isdigit() # True "12a45".isdigit() # False

.isalpha()

строка.isalpha()
Проверяет, состоит ли строка только из букв. Возвращает True или False.
"abc".isalpha() # True "abc123".isalpha() # False

📋 Методы списков

.append()

список.append(элемент)
Добавляет элемент в конец списка. Изменяет исходный список.
lst = [1, 2, 3] lst.append(4) # [1, 2, 3, 4]

.insert()

список.insert(индекс, элемент)
Вставляет элемент на указанную позицию. Элементы справа сдвигаются. Изменяет исходный список.
lst = [1, 2, 3] lst.insert(1, 99) # [1, 99, 2, 3]

.remove()

список.remove(значение)
Удаляет первое вхождение указанного значения. Если значение не найдено — ошибка ValueError.
lst = [1, 2, 3, 2] lst.remove(2) # [1, 3, 2]

.pop()

список.pop(индекс)
Удаляет элемент по индексу и возвращает его. Если индекс не указан — удаляет последний элемент.
lst = [1, 2, 3] x = lst.pop() # x=3, lst=[1,2] y = lst.pop(0) # y=1, lst=[2]

.sort()

список.sort(reverse=False)
Сортирует список на месте (изменяет исходный). reverse=True — по убыванию.
lst = [3, 1, 2] lst.sort() # [1, 2, 3] lst.sort(reverse=True) # [3, 2, 1]
См. также: sorted()

.index()

список.index(значение)
Возвращает индекс первого вхождения указанного значения. Если не найдено — ошибка ValueError.
[10, 20, 30].index(20) # 1

.count() (списки)

список.count(значение)
Подсчитывает, сколько раз значение встречается в списке.
[1, 2, 1, 3, 1].count(1) # 3

.clear()

список.clear()
Удаляет все элементы из списка. Список становится пустым.
lst = [1, 2, 3] lst.clear() # []

.copy()

список.copy()
Создаёт поверхностную копию списка. Изменения копии не затрагивают оригинал.
a = [1, 2, 3] b = a.copy() # b = [1, 2, 3]

.extend()

список.extend(другой_список)
Добавляет все элементы из другого списка в конец текущего. Изменяет исходный список.
a = [1, 2] a.extend([3, 4]) # [1, 2, 3, 4]

📖 Методы словарей

.get()

словарь.get(ключ, значение_по_умолчанию)
Безопасно получает значение по ключу. Если ключ не найден — возвращает None или указанное значение по умолчанию. Не вызывает ошибку KeyError.
d = {"a": 1} d.get("a") # 1 d.get("b") # None d.get("b", 0) # 0

.keys()

словарь.keys()
Возвращает объект со всеми ключами словаря. Можно перебирать в цикле for.
for key in d.keys(): print(key)

.values()

словарь.values()
Возвращает объект со всеми значениями словаря.
for val in d.values(): print(val)

.items()

словарь.items()
Возвращает объект с парами (ключ, значение). Самый популярный метод для перебора словаря.
for key, val in d.items(): print(key, "→", val)

.pop() (словари)

словарь.pop(ключ, значение_по_умолчанию)
Удаляет ключ из словаря и возвращает его значение. Если ключ не найден и указано умолчание — возвращает его, иначе ошибка KeyError.
d = {"a": 1, "b": 2} val = d.pop("a") # val=1, d={"b":2} val = d.pop("c", 0) # val=0 (ключа нет)

.update()

словарь.update(другой_словарь)
Добавляет все пары из другого словаря. Если ключи совпадают — значения перезаписываются.
d = {"a": 1} d.update({"b": 2, "c": 3}) # {'a':1, 'b':2, 'c':3}

📂 Методы файлов

.read()

файл.read()
Читает всё содержимое файла и возвращает его в виде одной строки.
with open("f.txt", "r") as f: text = f.read()

.readline()

файл.readline()
Читает из файла одну строку (до символа \n включительно). При достижении конца файла возвращает пустую строку.
line = f.readline()

.readlines()

файл.readlines()
Читает все строки файла и возвращает список строк (каждая с \n на конце).
lines = f.readlines() # ['строка1\n', 'строка2\n', ...]

🔑 Ключевые слова и операторы

with ... as

with open(...) as переменная:
Конструкция для безопасной работы с файлами. Гарантирует автоматическое закрытие файла после выхода из блока, даже если возникла ошибка.
with open("file.txt", "r") as f: data = f.read() # Файл автоматически закрыт

def

def имя(параметры):
Ключевое слово для создания (определения) функции. После def идёт имя функции, круглые скобки с параметрами и двоеточие.
def add(a, b): return a + b
См. также: return

return

return значение
Завершает выполнение функции и возвращает указанное значение в место вызова. Если return не указан, функция возвращает None.
def add(a, b): return a + b

pass

pass
Пустая операция-заглушка. Используется там, где синтаксис требует кода, но по логике там пока ничего нет (заглушка функции, пустой класс, пустой if).
def future_function(): pass # Реализую позже

in

элемент in коллекция
Оператор проверки вхождения. Возвращает True, если элемент есть в коллекции (списке, строке, словаре — проверяются ключи).
"a" in "abc" # True 3 in [1, 2, 3] # True "x" in {"x": 1} # True (ключ) 1 in {"x": 1} # False (значения не проверяются)

break

break
Немедленно прерывает выполнение цикла. Управление передаётся на первую строку после цикла.
for i in range(10): if i == 5: break # Выход из цикла при i=5
См. также: continue

continue

continue
Пропускает оставшуюся часть текущей итерации цикла и переходит к следующей итерации.
for i in range(5): if i == 2: continue # Пропустить i=2 print(i) # 0, 1, 3, 4
См. также: break

try...except

try: # опасный код except ТипОшибки: # что делать при ошибке finally: # выполнится всегда (необязательно)
Конструкция для обработки ошибок. Код в try выполняется; если возникает ошибка указанного типа — выполняется except. Блок finally (если есть) выполняется всегда.
try: x = int("abc") except ValueError: print("Не число!")
