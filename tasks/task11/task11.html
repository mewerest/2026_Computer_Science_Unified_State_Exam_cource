О задании

Задание 11 проверяет умение подсчитывать информационный объём текстового сообщения. В отличие от задания 7, здесь мы работаем с текстовой информацией: серийными номерами, идентификаторами, паролями. Используются формулы: N = 2ⁱ (вес символа) и I = L·i (объём сообщения). Вся сложность — в правильном округлении.

Тип 3 Мощность алфавита

Даны объём и длина сообщения. Нужно найти мощность алфавита. Алгоритм: V → I (объём одного символа) → i → N = 2ⁱ.

Задача №1

📋 Полная формулировка

Артур отправил Вике сообщение о переносе вебинара, оно состоит из 1024 символов и занимает 2 Кбайт памяти. Определите мощность алфавита, из которого составлено данное сообщение.

📌 Кратко: L = 1024 символа, V = 2 Кбайт. Найти: N.

1 Объём в битах: V = 2 × 2¹³ = 2¹⁴ бит.

2 Вес одного символа: i = V / L = 2¹⁴ / 1024 = 2¹⁴ / 2¹⁰ = 2⁴ = 16 бит.

3 Мощность алфавита: N = 2¹⁶ = 65 536.

# V = 2 Кбайт = 2 * 2^13 бит, L = 1024 = 2^10
# i = V / L = 2^14 / 2^10 = 2^4 = 16 бит
# N = 2^16
print(2 ** 16)  # 65536

💡 Пояснение: задача решается в одну строку — все числа уже являются степенями двойки. Аналитическое решение здесь проще и быстрее программного.

Ответ: 65536

Тип 2 Объём памяти для хранения

Даны: мощность алфавита, длина сообщения, количество сообщений (иногда + доп. информация). Нужно найти объём памяти для хранения всех сообщений.

Задача №2

📋 Полная формулировка

Для регистрации на образовательной платформе обязательно создание пароля длиной 6 символов. Для символов допущено использование заглавных букв (всего используется 26 букв) и десятичных цифр в любом порядке. В данном случае используется посимвольное кодирование паролей, что обеспечивает кодировку всех символов равным минимально возможным количеством бит. Пароли заносятся в единую базу, каждый занимает равное минимально возможное целое возможное количество байт. В качестве задания вычислите, сколько байт понадобится для хранения 20 паролей.

📌 Кратко: L = 6, алфавит: 26 букв + 10 цифр = 36 символов, 20 паролей. Найти: V в байтах.

1 N = 26 + 10 = 36. log₂36 ≈ 5,17 → i = 6 бит.

2 Вес одного пароля в битах: I₁ = 6 × 6 = 36 бит.

3 В байтах: 36 / 8 = 4,5 → округляем вверх → 5 байт.

4 Для 20 паролей: 5 × 20 = 100 байт.

from math import ceil, log2

L = 6
N = 26 + 10
Q = 20

i = ceil(log2(N))
V1 = ceil((L * i) / 8)
V_all = V1 * Q
print(V_all)
Ответ: 100

Задача №3

📋 Полная формулировка

Для регистрации в сети обязательно создание пароля длиной 32 символа. Пароль должен состоять из десятичных цифр и символов из 240-символьного специального алфавита в нижнем регистре. Пароли запоминаются в единую базу, для этого отведено равное минимально возможное целое возможное количество байт. В пароле используется посимвольное кодирование, что означает кодировку всех символов равным минимально возможным количеством бит. Вычислите, сколько нужно объема для сохранения информации о 3200 пользователях. Запишите ответ в Кбайтах.

📌 Кратко: L = 32, N = 10 + 240 = 250, пользователей — 3200. Найти: V в Кбайт.

1 N = 250. log₂250 ≈ 7,97 → i = 8 бит.

2 Вес одного пароля в битах: I₁ = 32 × 8 = 256 бит = 32 байта (256 / 8 = 32, ровно).

3 Для 3200 пользователей: 32 × 3200 = 102 400 байт = 102 400 / 2¹⁰ = 100 Кбайт.

from math import ceil, log2

L = 32
N = 10 + 240
Q = 3200

i = ceil(log2(N))
V1 = ceil((L * i) / 8)
V_all = V1 * Q
print(V_all // 1024)
Ответ: 100

Задача №4

📋 Полная формулировка

При регистрации в компьютерной системе каждому объекту присваивается идентификатор, состоящий из 20 символов и содержащий только символы из 26-символьного латинского алфавита от A до Z без учёта регистра. В базе данных для хранения сведений о каждом идентификаторе отведено одинаковое и минимально возможное целое число байт. При этом используется посимвольное кодирование идентификаторов, все символы кодируются одинаковым и минимально возможным количеством бит. Определите объём памяти (в байтах), необходимый для хранения сведений о 50 объектах. В ответе запишите только целое число — количество байт.

📌 Кратко: L = 20, N = 26, объектов — 50. Найти: V в байтах.

1 N = 26. log₂26 ≈ 4,7 → i = 5 бит.

2 Вес одного идентификатора в битах: I₁ = 20 × 5 = 100 бит.

3 В байтах: 100 / 8 = 12,5 → 13 байт.

4 Для 50 объектов: 13 × 50 = 650 байт.

from math import ceil, log2

L = 20
N = 26
Q = 50

i = ceil(log2(N))
V1 = ceil((L * i) / 8)
V_all = V1 * Q
print(V_all)
Ответ: 650

Задача №5

📋 Полная формулировка

В одной компании новым работникам выдается цифровой пропуск, который включает в себя личный код и дополнительную информацию. Личный код длиной 11 символов включает в себя буквы латинского алфавита, причем только прописные, а также значения из диапазона [0, 9]. Под личные коды выделено равное минимально возможное целое количество байт. Стоит отметить, что в личном коде используется посимвольное кодирование, это обеспечивает кодировку всех символов равным минимально возможным количеством бит. Кроме собственно пароля, для каждого пользователя в системе хранятся дополнительные сведения, для чего выделено целое число байт; это число одно и то же для всех пользователей. Для хранения сведений о 30 пользователях потребовалось 750 байт. Вычислите объем памяти (в целых байтах), нужный для хранения дополнительных сведений об одном пользователе. Примечание: латинский алфавит содержит в себе 26 символов.

📌 Кратко: личный код: L = 11, N = 26 + 10 = 36. 30 пользователей → 750 байт всего. Найти: доп. сведения на одного пользователя (в байтах).

1 N = 36. log₂36 ≈ 5,17 → i = 6 бит.

2 Вес личного кода в битах: 11 × 6 = 66 бит. В байтах: 66 / 8 = 8,25 → 9 байт.

3 Всего на одного: 750 / 30 = 25 байт (ровно).

4 Доп. сведения на одного: 25 − 9 = 16 байт.

from math import ceil, log2

L = 11
N = 26 + 10
Q = 30
V_total = 750

i = ceil(log2(N))
V_code = ceil((L * i) / 8)
V_per_user = V_total // Q
V_extra = V_per_user - V_code
print(V_extra)
Ответ: 16

Задача №6

📋 Полная формулировка

Для регистрации в сети обязательно создание пароля из 9 символов. Для символов пароля допущены только 26 символов местного алфавита в обоих регистрах и значения из диапазона [0, 9]. Пароли заносятся в единую базу, для каждого пароля выделено равное минимально возможное целое число байт. В пароле используется посимвольное кодирование, что обеспечивает кодировку всех символов одинаковым минимально возможным количеством бит. Плюсом к паролю база хранит дополнительную информацию (18 байт) для каждого зарегистрировавшегося пользователя. Для хранения информации о всех пользователях выделено 1 Кбайт. Определите наибольшее количество пользователей, о которых возможно сохранить информацию.

📌 Кратко: пароль: L = 9, N = 26×2 + 10 = 62. Доп. информация — 18 байт/чел. Всего памяти — 1 Кбайт = 1024 байта. Найти: макс. количество пользователей.

1 N = 26×2 + 10 = 62. log₂62 ≈ 5,95 → i = 6 бит.

2 Вес пароля в битах: 9 × 6 = 54 бита. В байтах: 54 / 8 = 6,75 → 7 байт.

3 Всего на одного: 7 + 18 = 25 байт.

4 Количество пользователей: 1024 / 25 = 40,96 → округляем вниз → 40.

from math import ceil, log2

L = 9
N = 26 * 2 + 10
extra = 18
V_total = 1024  # 1 Кбайт

i = ceil(log2(N))
V1 = ceil((L * i) / 8) + extra
Q = V_total // V1  # целочисленное деление — округление вниз
print(Q)
Ответ: 40

Задача №7 ★ составной с диапазоном

📋 Полная формулировка

В одной компании новым работникам выдается цифровой пропуск, который включает в себя личный код, номер подразделения и дополнительную информацию. Личный код длиной 17 символов включает в себя буквы латинского алфавита, причем обоих регистров, а также значения из диапазона [0, 9] и любые символы из набора @#$%^&*(). Под личные коды выделено равное минимально возможное количество байт. В личном коде используется посимвольное кодирование, номер подразделения — это целое значение в диапазоне [1, 1200], также номер подразделения кодируется независимо от личного кода и занимает минимально возможным количеством байт. Вычислите, какой объем (в байтах) нужно зарезервировать под дополнительную информацию, при условии, что всего для цифрового пропуска выделено 48 байт.

📌 Кратко: личный код: L = 17, N = 26×2 + 10 + 10 = 72. Номер подразделения: диапазон [1, 1200] (N = 1200). Всего на пропуск — 48 байт. Найти: доп. информация в байтах.

🔍 Номер подразделения — диапазон чисел: N = 1200 − 1 + 1 = 1200. log₂1200 ≈ 10,23 → i = 11 бит. Подробнее: кодирование чисел.

1 Личный код. N = 52 + 10 + 10 = 72. log₂72 ≈ 6,17 → i₁ = 7 бит.

2 Вес личного кода: 17 × 7 = 119 бит → 119 / 8 = 14,875 → 15 байт.

3 Номер подразделения. N = 1200. log₂1200 ≈ 10,23 → i₂ = 11 бит.

4 Вес номера: 11 / 8 = 1,375 → 2 байта.

5 Доп. информация = 48 − 15 − 2 = 31 байт.

from math import ceil, log2

# Поле 1: личный код
N1 = 26 * 2 + 10 + 10  # буквы обоих регистров + цифры + спецсимволы
i1 = ceil(log2(N1))
V1 = ceil((17 * i1) / 8)

# Поле 2: номер подразделения [1, 1200]
N2 = 1200  # 1200 - 1 + 1
i2 = ceil(log2(N2))
V2 = ceil(i2 / 8)

V_total = 48
V_extra = V_total - V1 - V2
print(V_extra)
Ответ: 31

Тип 1 Длина серийного номера

Даны: мощность алфавита, количество сообщений, объём памяти. Нужно найти максимальную длину одного сообщения. Формула: L = I₁ / i.

Задача №8

📋 Полная формулировка

На предприятии каждой изготовленной детали присваивают серийный номер, содержащий десятичные цифры, 52 латинские буквы (с учётом регистра) и символы из 963-символьного специального алфавита. В базе данных для хранения каждого серийного номера отведено одинаковое и минимально возможное число байт. При этом используется посимвольное кодирование серийных номеров, все символы кодируются одинаковым и минимально возможным числом бит. Известно, что для хранения 2000 серийных номеров отведено не более 693 Кбайт памяти. Определите максимально возможную длину серийного номера. В ответе запишите только целое число.

📌 Кратко: N = 10 + 52 + 963 = 1025. 2000 номеров, V ≤ 693 Кбайт. Найти: Lmax.

1 N = 1025. log₂1025 ≈ 10,001 → 2¹⁰ = 1024 не хватает → i = 11 бит.

2 Память на 2000 номеров: 693 × 2¹⁰ = 709 632 байт.

3 Вес одного номера: I₁ = 709 632 / 2000 ≈ 354,8 → «не более» → округляем вниз → 354 байта.

4 Длина: L = 354 × 8 / 11 ≈ 257,45 → округляем вниз → 257.

from math import ceil, log2

N = 10 + 52 + 963
i = ceil(log2(N))
Q = 2000
V_lim = 693 * 1024  # Кбайт → байты

# «не более» → ищем максимальную длину
for L in range(1, 1000)[::-1]:
    V1 = ceil((L * i) / 8)
    if V1 * Q <= V_lim:
        print(L)
        break
Ответ: 257

Тип 3 Мощность алфавита (продолжение)

Задача №9

📋 Полная формулировка

На предприятии каждой изготовленной детали присваивают серийный номер, состоящий из 261 символов. Для его хранения отведено одинаковое и минимально возможное число байт. При этом используется посимвольное кодирование серийных номеров, все символы кодируются одинаковым и минимально возможным числом бит. Известно, что для хранения 252500 серийных номеров отведено более 32 Мбайт памяти. Определите минимально возможную мощность алфавита, из которого составляются серийные номера. В ответе запишите только число.

📌 Кратко: L = 261, 252 500 номеров, V > 32 Мбайт. Найти: Nmin.

1 Память на все номера: 32 × 2²⁰ = 33 554 432 байт.

2 Вес одного номера: I₁ = 33 554 432 / 252 500 ≈ 132,89 → «более» → округляем вверх → 133 байта.

3 Вес символа: i = 133 × 8 / 261 ≈ 4,076 → «более» → округляем вверх → 5 бит.

4 Минимальная мощность: Nmin = 2⁴ + 1 = 17.

from math import ceil, log2

L = 261
Q = 252_500
V_lim = 32 * 1024 * 1024  # Мбайт → байты

# Перебираем мощность алфавита
for n in range(1, 1000):
    i = ceil(log2(n))
    V1 = ceil((L * i) / 8)
    if V1 * Q > V_lim:  # «более»
        print(n)
        break
Ответ: 17
