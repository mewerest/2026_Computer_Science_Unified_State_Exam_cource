Позиционные системы счисления

Позиционная система счисления — система, в которой значение каждой цифры зависит от её позиции (разряда) в записи числа. Основание системы определяет, сколько различных цифр используется.

В задании 14 ЕГЭ используются системы счисления с основанием от 2 до 36. Важнейшие из них:

  • Двоичная (основание 2): цифры 0, 1
  • Восьмеричная (основание 8): цифры 0–7
  • Шестнадцатеричная (основание 16): цифры 0–9 и буквы A–F

В общем случае для оснований больше 10 используются буквы латинского алфавита: A=10, B=11, ..., Z=35.

💡 Взаимосвязь систем: восьмеричная и шестнадцатеричная системы напрямую связаны с двоичной. Одна восьмеричная цифра = 3 двоичных разряда, одна шестнадцатеричная = 4 двоичных разряда. Это позволяет быстро переводить числа между ними без вычислений.

Формирование алфавита системы счисления

В Python алфавит любой системы счисления (вплоть до 36-ричной) можно сформировать из двух стандартных строк модуля string:

from string import digits, ascii_uppercase

# digits = '0123456789'
# ascii_uppercase = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'
alph = digits + ascii_uppercase

# Алфавит 19-ричной системы (первые 19 символов):
print(alph[:19])  # '0123456789ABCDEFGHI'

🔍 Как использовать: если x — неизвестная цифра в системе с основанием N, то x может принимать значения из alph[:N]. Для перебора от наибольшего к наименьшему используем срез alph[:N][::-1].

Перевод чисел в Python

Python предоставляет встроенные функции для перевода чисел между системами счисления:

# Строка → десятичное число (любое основание от 2 до 36)
n = int('1A3', 16)    # n = 419

# Десятичное число → строка в двоичной системе
s = bin(255)          # s = '0b11111111'

# Десятичное число → строка в восьмеричной системе
s = oct(255)          # s = '0o377'

# Десятичное число → строка в шестнадцатеричной системе
s = hex(255)          # s = '0xff'

# Для произвольного основания (кроме 2, 8, 16) — только через int()
# Прямого аналога bin/oct/hex для других оснований нет

⚠️ Важно: int() позволяет перевести строку с буквами в десятичное число, указав основание вторым аргументом. Например: int('98897A21', 19) — переводит число из 19-ричной системы в десятичную. А bin(), oct(), hex() работают только в направлении «десятичное → строка» и только для оснований 2, 8, 16.

Основания больше 36

В некоторых задачах ЕГЭ встречаются системы счисления с основанием больше 36 (например, 150). Стандартный метод с alph[:N] здесь не работает — в алфавите всего 36 символов.

Для оснований > 36 неизвестная цифра x — это целое число от 0 до основания−1. Перевод числа в десятичную систему выполняется по формуле разложения:

abcdeN = a·N⁴ + b·N³ + c·N² + d·N¹ + e·N⁰
Каждая цифра умножается на основание в степени, равной её позиции (нумерация справа налево, начиная с 0).

Пример: число 51x29₁₅₀

# 51x29₁₅₀ — позиции цифр справа налево: 0, 1, 2, 3, 4
# 9·150⁰ + 2·150¹ + x·150² + 1·150³ + 5·150⁴
# Перебираем x от 0 до 149

for x in range(150)[::-1]:  # от большего к меньшему
    n1 = 5 * 150**4 + 1 * 150**3 + x * 150**2 + 2 * 150 + 9
    n2 = x * 150**3 + 0 * 150**2 + 2 * 150 + 3
    res = n1 + n2
    if res % 149 == 0:
        print(res // 149)
        break

💡 Универсальный подход: можно написать функцию для автоматического перевода строки с неизвестной цифрой в десятичное число. Но в ЕГЭ проще один раз расписать разряды вручную — это занимает 2 минуты и исключает ошибки.

Приведение к единому основанию

В некоторых задачах выражение состоит из степеней чисел 4, 8, 16, 32, 64, 256, 1024, 4096 и т.д. Все они являются степенями двойки. Чтобы анализировать двоичную запись такого выражения, нужно привести все слагаемые к степеням одного основания:

a = 2ⁿ → ak = (2ⁿ)k = 2n·k
Примеры:
4k = (2²)k = 22k
8k = 23k
16k = 24k
64k = 26k
256k = 28k
1024k = 210k
4096k = 212k

💡 Зачем это нужно: после приведения к степеням двойки можно понять, на каких позициях в двоичной записи стоят единицы, а на каких — нули. Это позволяет решать задачи без программирования: единица в степени 2m даёт единицу в m-м разряде двоичной записи (разряды считаются с нуля).

📖 Пример:

4¹⁰ + 8⁵ − 2³ = (2²)¹⁰ + (2³)⁵ − 2³ = 2²⁰ + 2¹⁵ − 2³.
В двоичной записи: единицы в разрядах 20 и 15, минус единица в разряде 3 (превращается в цепочку единиц из-за заёма).

Подсчёт цифр в записи числа

Для подсчёта количества определённых цифр в числе, записанном в системе счисления с основанием base, используется стандартный алгоритм с последовательным делением:

count = 0
while num:
    if num % base == искомое_значение:
        count += 1
    num //= base

Как это работает: num % base даёт последнюю цифру числа в системе с основанием base. num //= base отбрасывает эту цифру. Цикл повторяется, пока число не станет равно 0.

Условие внутри цикла можно заменить на любое другое: подсчёт цифр больше/меньше заданного значения, подсчёт ненулевых цифр и т.д.

Сумма цифр в записи числа

Модификация алгоритма подсчёта: вместо увеличения счётчика на 1, прибавляем значение цифры к сумме. Условие может фильтровать цифры (например, «только цифры ≤ 17»), а может отсутствовать — тогда суммируются все цифры.

# Сумма всех цифр (без условий)
summa = 0
while num:
    summa += num % base
    num //= base

# Сумма цифр с условием (например, только ≤ 17)
summa = 0
while num:
    digit = num % base
    if digit <= 17:
        summa += digit
    num //= base

💡 Отличие от подсчёта количества: переменная summa накапливает сумму значений цифр. Если условие не нужно — просто убираем if.

Значащие и незначащие нули

Значащие нули — нули, которые являются частью числа и не могут быть отброшены без изменения его значения.

Незначащие нули — нули, добавленные слева от числа для удобства записи. Их можно отбросить, значение числа не изменится.

Примеры:

  • 1 = 01 = 001 = 0001 — нули слева незначащие.
  • 1, 10, 100, 1000 — нули справа значащие, они меняют порядок числа.
  • В числе 101 все нули — значащие (находятся между ненулевыми цифрами).

💡 В программировании: алгоритм подсчёта цифр через деление (while num: ... num //= base) всегда учитывает только значащие нули, так как цикл останавливается, когда число становится равным 0. Незначащие нули слева не сохраняются в числовой переменной.

Шаблоны кода для задания 14

В этом разделе собраны универсальные программные шаблоны для решения задач задания 14. Достаточно подставить данные из условия — и программа найдёт ответ.

Шаблон 1: Подсчёт цифр в выражении (без неизвестных)

Когда использовать: дано конкретное арифметическое выражение, нужно найти количество определённых цифр в его записи в заданной системе счисления.

# Что подставить:
#   num — значение выражения (вычислить заранее)
#   base — основание системы счисления
#   target — какую цифру ищем (или условие: > 10, <= 17 и т.д.)

num = 3 * 3125**8 + 2 * 625**7 - 4 * 625**6 + 3 * 125**5 - 2 * 25**4 - 2025
base = 25
target = 0  # ищем нули

count = 0
while num:
    if num % base == target:
        count += 1
    num //= base
print(count)

Шаблон 2: Выражение с неизвестным x

Когда использовать: дано выражение с переменной x (целое число в заданном диапазоне), нужно найти x, при котором в записи числа содержится определённое количество цифр.

# Что подставить:
#   выражение — формула с x (например, 7**170 + 7**100 - x)
#   base — основание системы счисления
#   target — искомое количество цифр
#   x_range — диапазон значений x (например, range(1, 2031))
#   искать максимум → range(...)[::-1], минимум → range(...)

for x in range(1, 2031)[::-1]:  # от большего к меньшему
    num = 7**170 + 7**100 - x
    count = 0
    while num:
        if num % 7 == 0:
            count += 1
        num //= 7
    if count == 71:
        print(x)
        break

Шаблон 3: Выражение с неизвестной цифрой в числе (основание ≤ 36)

Когда использовать: в числах выражения одна цифра заменена на x (цифра системы счисления с основанием ≤ 36).

from string import digits, ascii_uppercase
alph = digits + ascii_uppercase

for x in alph[:19][::-1]:  # 19-ричная, от большего к меньшему
    n1 = int(f'98897{x}21', 19)
    n2 = int(f'2{x}923', 19)
    res = n1 + n2
    if res % 18 == 0:
        print(res // 18)
        break

Шаблон 4: Выражение с неизвестной цифрой (основание > 36)

Когда использовать: основание системы счисления больше 36. Перебираем x как целое число от 0 до основания−1, а числа переводим через разряды.

# Пример для основания 150: 51x29₁₅₀ + x023₁₅₀
# Разряды числа 51x29: 9·150⁰ + 2·150¹ + x·150² + 1·150³ + 5·150⁴
# Разряды числа x023:  3·150⁰ + 2·150¹ + 0·150² + x·150³

for x in range(150)[::-1]:  # от большего к меньшему
    n1 = 5*150**4 + 1*150**3 + x*150**2 + 2*150 + 9
    n2 = x*150**3 + 0*150**2 + 2*150 + 3
    res = n1 + n2
    if res % 149 == 0:
        print(res // 149)
        break

Шаблон 5: Сумма всех цифр (без условия)

Когда использовать: нужно найти сумму всех цифр в записи числа, без фильтрации.

num = 5**20 + 5**10 - 5**13 - 5**3
base = 5
summa = 0
while num:
    summa += num % base
    num //= base
print(summa)

Шаблон 6: Поиск x по сумме цифр

Когда использовать: нужно найти x, при котором сумма цифр в записи выражения равна заданному числу.

# Выражение: 27^7 - 3^11 + 36 - x, троичная система, сумма цифр = 22
for x in range(1, 10000):
    num = 27**7 - 3**11 + 36 - x
    summa = 0
    while num:
        summa += num % 3
        num //= 3
    if summa == 22:
        print(x)
        break

Шаблон 7: Поиск x с максимальным количеством цифр

Когда использовать: нужно найти x, при котором количество определённых цифр максимально (а не равно конкретному числу).

# Выражение: 4^210 + 4^110 - x, x ∈ [1, 3000], четверичная система
# Найти x с максимальным количеством нулей
max_count = -1
best_x = 0
for x in range(1, 3001):
    num = 4**210 + 4**110 - x
    count = 0
    while num:
        if num % 4 == 0:
            count += 1
        num //= 4
    if count > max_count:
        max_count = count
        best_x = x
print(best_x)

💡 Универсальное правило: для задач с выражением без x — прямое вычисление и подсчёт. Для задач с x — перебор в цикле. Для задач с x в цифре числа — перебор с f-строками (основание ≤ 36) или через разряды (основание > 36). Для задач с суммой цифр — замена count на summa.
