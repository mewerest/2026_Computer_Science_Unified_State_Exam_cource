О задании

Задание 14 — повышенного уровня сложности, на решение отводится около 3 минут. Проверяется умение работать с позиционными системами счисления: вычислять значения арифметических выражений, подсчитывать цифры в записи числа, находить неизвестные параметры.

Все задания решаются программно на Python. Основной инструмент — алгоритм подсчёта цифр через последовательное деление на основание системы счисления.

Тип 1 Выражение без неизвестных

Дано конкретное арифметическое выражение. Нужно найти количество или сумму определённых цифр в его записи в заданной системе счисления. Самый простой тип — прямое вычисление и подсчёт.

Задача №1

📋 Полная формулировка

Сколько единиц в двоичной записи числа 4096²¹⁰ − 1024⁶⁷ + 256³² − 64?

📌 Кратко: вычислить выражение, перевести в двоичную систему, подсчитать количество единиц.
num = 4096**210 - 1024**67 + 256**32 - 64
binary = bin(num)[2:]
print(binary.count('1'))
Ответ: 2100

Задача №2

📋 Полная формулировка

Значение арифметического выражения: 9⁸ + 3²⁴ − 3 × 7 записали в системе счисления с основанием 3. Сколько цифр «2» содержится в этой записи?

📌 Кратко: вычислить выражение, в 3-чной записи подсчитать количество цифр «2».
num = 9**8 + 3**24 - 3 * 7
count = 0
while num:
    if num % 3 == 2: count += 1
    num //= 3
print(count)
Ответ: 14

Задача №3

📋 Полная формулировка

Определите в 25-ричной записи числа количество цифр с числовым значением, превышающим 10: 4 × 3125²⁰¹⁹ + 3 × 625²⁰²⁰ − 2 × 125²⁰²¹ + 25²⁰²² − 4 × 5²⁰²³ − 2024.

📌 Кратко: вычислить выражение, в 25-ричной записи подсчитать цифры > 10.
num = (4 * 3125**2019 + 3 * 625**2020 - 2 * 125**2021
       + 25**2022 - 4 * 5**2023 - 2024)
count = 0
while num:
    if num % 25 > 10: count += 1
    num //= 25
print(count)
Ответ: 3030

Задача №4 ★ сумма цифр с условием

📋 Полная формулировка

Значение арифметического выражения 3 × 289²⁰²⁴ + 81 × 49¹²¹ − 9 × 16⁸¹ − 6011 записали в системе счисления с основанием 31. Определите сумму цифр с числовым значением, не превышающим 17, в записи этого числа.

📌 Кратко: вычислить выражение, в 31-ричной записи найти сумму цифр ≤ 17.

🔍 Сумма цифр с условием: сумма цифр →

num = (3 * 289**2024 + 81 * 49**121 - 9 * 16**81 - 6011)
base = 31
summa = 0
while num:
    digit = num % base
    if digit <= 17: summa += digit
    num //= base
print(summa)
Ответ: 16750

Задача №5 ★ сумма всех цифр

📋 Полная формулировка

Число, являющееся результатом выражения 5²⁰ + 5¹⁰ − 5¹³ − 5³, записали в системе счисления с основанием 5. Чему равна сумма цифр в получившейся записи? В ответе укажите одно десятичное число — сумма разрядов пятеричного числа.

📌 Кратко: вычислить выражение, найти сумму всех цифр в 5-ричной записи.
num = 5**20 + 5**10 - 5**13 - 5**3
summa = 0
while num:
    summa += num % 5
    num //= 5
print(summa)
Ответ: 56

Тип 2 Выражение с неизвестным числом x

Дано арифметическое выражение с переменной x. Нужно найти x, при котором в записи значения выражения содержится определённое количество цифр (или сумма цифр равна заданной, или количество цифр максимально).

Задача №6

📋 Полная формулировка

Значение арифметического выражения 3¹⁰⁰ − x, где x — целое положительное число, не превышающее 2030, записали в троичной системе счисления. Определите наибольшее значение x, при котором в троичной записи числа содержится ровно пять нулей.

📌 Кратко: 3¹⁰⁰ − x, x ∈ [1, 2030], троичная система, ровно 5 нулей. Найти: наибольшее x.
for x in range(1, 2031)[::-1]:
    num = 3**100 - x
    count = 0
    while num:
        if num % 3 == 0: count += 1
        num //= 3
    if count == 5:
        print(x)
        break
Ответ: 2024

Задача №7

Значение арифметического выражения 7⁹¹ + 7¹⁶⁰ − x, где x — целое положительное число, не превышающее 2030, записали в 7-ричной системе счисления. Определите наибольшее значение x, при котором в 7-ричной записи числа содержится ровно 70 нулей.

📌 Кратко: 7⁹¹ + 7¹⁶⁰ − x, x ∈ [1, 2030], 7-ричная система, ровно 70 нулей. Найти: наибольшее x.
for x in range(1, 2031)[::-1]:

Задача №8 ★ x по сумме цифр

📋 Полная формулировка

Значение выражения 27⁷ − 3¹¹ + 36 − x записали в троичной системе счисления, при этом сумма цифр в записи оказалась равной 22. При каком минимальном натуральном x это возможно?

📌 Кратко: 27⁷ − 3¹¹ + 36 − x, троичная система, сумма цифр = 22. Найти: минимальное x.

🔍 Поиск по сумме цифр: перебираем x, вычисляем сумму всех цифр, сравниваем с 22. Подробнее →

for x in range(1, 10000):
    num = 27**7 - 3**11 + 36 - x
    summa = 0
    while num:
        summa += num % 3
        num //= 3
    if summa == 22:
        print(x)
        break
Ответ: 6

Задача №9 ★ x с максимумом нулей

📋 Полная формулировка

Значение арифметического выражения 4²¹⁰ + 4¹¹⁰ − x, где x — целое положительное число, не превышающее 3000, записали в четверичной системе счисления. Определите наименьшее значение x, при котором в четверичной записи числа содержится наибольшее количество нулей.

📌 Кратко: 4²¹⁰ + 4¹¹⁰ − x, x ∈ [1, 3000], четверичная система, найти x с макс. количеством нулей (наименьший).

🔍 Поиск максимума: перебираем все x, для каждого считаем количество нулей, отслеживаем максимум. Шаблон 7 →

max_count = -1
best_x = 0
for x in range(1, 3001):
    num = 4**210 + 4**110 - x
    count = 0
    while num:
        if num % 4 == 0: count += 1
        num //= 4
    if count > max_count:
        max_count = count
        best_x = x
print(best_x)
Ответ: 1024

Тип 3 Выражение с неизвестной цифрой в числе

В числах выражения одна цифра заменена на x (цифра заданной системы счисления). Нужно найти x, при котором выражение кратно заданному числу, и вычислить результат.

Задача №10

📋 Полная формулировка

Операнды арифметического выражения записаны в системе счисления с основанием 15: 97968x15₁₅ + 7x233₁₅. Определите наименьшее значение x, при котором значение выражения кратно 14. Для найденного x вычислите частное от деления на 14.

📌 Кратко: система 15, наименьший x (кратность 14), частное от деления на 14.
from string import digits, ascii_uppercase
alph = digits + ascii_uppercase

for x in alph[:15]:
    n1 = int(f'97968{x}15', 15)
    n2 = int(f'7{x}233', 15)
    res = n1 + n2
    if res % 14 == 0:
        print(res // 14)
        break
Ответ: 116071912

Задача №11

📋 Полная формулировка

Операнды арифметического выражения записаны в системе счисления с основанием 19: 98x79641₁₉ + 36x14₁₉ + 73x4₁₉. Определите наибольшее значение x, при котором значение выражения кратно 18. Для найденного x вычислите частное от деления на 18.

📌 Кратко: система 19, наибольший x (кратность 18), частное от деления на 18.
from string import digits, ascii_uppercase
alph = digits + ascii_uppercase

for x in alph[:19][::-1]:
    n1 = int(f'98{x}79641', 19)
    n2 = int(f'36{x}14', 19)
    n3 = int(f'73{x}4', 19)
    res = n1 + n2 + n3
    if res % 18 == 0:
        print(res // 18)
        break
Ответ: 470402599

Задача №13 ★ основание 150

📋 Полная формулировка

Операнды арифметического выражения записаны в системе счисления с основанием 150: 51x29₁₅₀ + x023₁₅₀. Определите наибольшее значение x, при котором значение выражения кратно 149. Для найденного x вычислите частное от деления на 149.

📌 Кратко: система 150, наибольший x (кратность 149), частное от деления на 149.

🔍 Основание > 36: алфавит не работает, переводим через разряды. Подробнее →

# 51x29₁₅₀: 9·150⁰ + 2·150¹ + x·150² + 1·150³ + 5·150⁴
# x023₁₅₀:  3·150⁰ + 2·150¹ + 0·150² + x·150³
for x in range(150)[::-1]:
    n1 = 5*150**4 + 1*150**3 + x*150**2 + 2*150 + 9
    n2 = x*150**3 + 0*150**2 + 2*150 + 3
    res = n1 + n2
    if res % 149 == 0:
        print(res // 149)
        break
Ответ: 20157588
