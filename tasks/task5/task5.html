О задании

Задание 5 проверяет умение анализировать простые алгоритмы. Встречаются два типа задач: алгоритмы, работающие с записью числа в различных системах счисления, и алгоритмы, работающие напрямую с десятичными цифрами числа.

Ключевые навыки: перевод чисел между системами счисления, обработка строк, реализация условий «если... то...», извлечение и обработка цифр числа.

Тип 1 Алгоритмы с системами счисления

Строится запись числа N в заданной системе счисления, обрабатывается по правилам, результат переводится обратно в десятичную систему. Перевод чисел →

Задача №1

📋 Полная формулировка

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится двоичная запись числа N.
  2. Далее эта запись обрабатывается по следующему правилу:
    а) если число чётное, то к двоичной записи числа слева дописывается 10;
    б) если число нечётное, то к двоичной записи числа слева дописывается 1 и справа дописывается 01.
  3. Результат переводится в десятичную систему и выводится на экран.

Например, для исходного числа 4₁₀ = 100₂ результатом является число 20₁₀ = 10100₂, а для исходного числа 5₁₀ = 101₂ это число 53₁₀ = 110101₂.

Укажите максимальное число R, которое может быть результатом работы данного алгоритма, при условии, что N не больше 12.

res = []
for N in range(1, 13):
    R = f'{N:b}'
    if N % 2 == 0:
        R = '10' + R
    else:
        R = '1' + R + '01'
    R = int(R, 2)
    res.append(R)

print(max(res))
Ответ: 109

Задача №2

📋 Полная формулировка

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится троичная запись числа N.
  2. Далее эта запись обрабатывается по следующему правилу:
    а) если число N делится на 3, то к этой записи дописываются две последние троичные цифры;
    б) если число N на 3 не делится, то вычисляется сумма цифр полученной троичной записи, эта сумма переводится в троичную систему счисления и дописывается в конец числа.
  3. Результат переводится в десятичную систему и выводится на экран.

Например, для исходного числа 11₁₀ = 102₃ результатом является число 10210₃ = 102₁₀, а для исходного числа 12₁₀ = 110₃ это число 11010₃ = 111₁₀.

Укажите минимальное чётное число R, большее 220, которое может быть получено с помощью описанного алгоритма.

def to_ternary(num):
    result = ''
    while num:
        result += str(num % 3)
        num //= 3
    return result[::-1]

res = []
for N in range(1, 10_000):
    R = to_ternary(N)
    if N % 3 == 0:
        R += R[-2:]
    else:
        sum_d = sum(map(int, R))
        R += to_ternary(sum_d)
    R = int(R, 3)
    if R % 2 == 0 and R > 220:
        res.append(R)

print(min(res))
Ответ: 222

Задача №3

📋 Полная формулировка

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится восьмеричная запись числа N.
  2. Далее эта запись обрабатывается по следующему правилу:
    а) если количество чётных цифр в записи числа нечётно, то к трём последним разрядам восьмеричной записи справа дописывается 46;
    б) если количество чётных цифр в записи числа чётно, то остаток от деления числа на 8 умножается на 5, переводится в восьмеричную запись и дописывается слева.
  3. Результат переводится в десятичную систему и выводится на экран.

Например, для исходного числа 12 = 14₈ результатом является число 1446₈ = 806, а для исходного числа 777 = 1411₈ это число 41146₈ = 16998.

Укажите минимальное число R, которое может быть получено с помощью описанного алгоритма при N не меньшем 80. В ответ запишите это число в десятичной системе счисления.

def count_evens(num):
    evens = sum([1 for d in num
                 if int(d, 8) % 2 == 0])
    return evens

res = []
for N in range(80, 10000):
    R = f'{N:o}'
    if count_evens(R) % 2:
        R = R[-3:] + '46'
    else:
        R = f'{(N % 8 * 5):o}' + R
    R = int(R, 8)
    res.append(R)

print(min(res))

💡 Обрати внимание: перебираем все N от 80 до 10000, для каждого вычисляем R, собираем в список и находим минимальное. В отличие от задач, где ищется конкретное N по условию R == N, здесь ищется минимальное R среди всех возможных.

Ответ: 38

Задача №4 ★ замена символов

📋 Полная формулировка

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится двоичная запись числа N.
  2. Далее эта запись обрабатывается по следующему правилу:
    а) если число N чётное, то в этой записи каждая единица заменяется на 11;
    б) если число N нечётное, то в этой записи каждый нуль заменяется на 00.
  3. Результат переводится в десятичную систему и выводится на экран.

Например, для исходного числа 4₁₀ = 100₂ результат — 1100₂ = 12₁₀, а для исходного числа 5₁₀ = 101₂ это число 1001₂ = 9₁₀.

Укажите минимальное число N, после обработки которого с помощью этого алгоритма получается число R, большее 70.

🔍 Замена символов: метод .replace() →

for N in range(1, 1000):
    R = f'{N:b}'
    if N % 2 == 0:
        R = R.replace('1', '11')
    else:
        R = R.replace('0', '00')
    R = int(R, 2)
    if R > 70:
        print(N)
        break
Ответ: 14

Задача №5 ★ замена левых разрядов

📋 Полная формулировка

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится двоичная запись числа N.
  2. Далее, если исходное число N чётное, то справа к построенной двоичной записи числа N приписывается 0, если нечётное — приписывается 1.
  3. Далее полученная запись обрабатывается по следующему правилу:
    а) если количество единиц в двоичной записи кратно трём, то в этой записи два левых разряда заменяются на 11;
    б) если количество единиц в двоичной записи некратно трём, то в этой записи два левых разряда заменяются на 10.
  4. Результат переводится в десятичную систему.

Например, для исходного числа 6₁₀ = 110₂ результат — 1000₂ = 8₁₀, а для исходного числа 3₁₀ = 11₂ результат — 111₂ = 7₁₀.

Укажите минимальное число N, после обработки которого с помощью этого алгоритма получается число R, не меньшее чем 26.

🔍 Замена левых разрядов: приём →

for N in range(1, 1000):
    R = f'{N:b}'
    R += '0' if N % 2 == 0 else '1'
    if R.count('1') % 3 == 0:
        R = '11' + R[2:]
    else:
        R = '10' + R[2:]
    R = int(R, 2)
    if R >= 26:
        print(N)
        break
Ответ: 9

Задача №6 ★ копия / переворот

📋 Полная формулировка

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится двоичная запись числа N.
  2. Далее эта запись обрабатывается по следующему правилу:
    а) если число N делится на 4, то к этой записи дописывается справа она же;
    б) если число N на 4 не делится, то к этой записи дописывается справа эта же запись, но в обратном порядке.
  3. Результат переводится в десятичную систему.

Например, для исходного числа 4₁₀ = 100₂ результатом является число 100100₂ = 36₁₀, а для исходного числа 11₁₀ = 1011₂ это число 10111101₂ = 189₁₀.

Укажите минимальное число N, после обработки которого с помощью этого алгоритма получается число R, не меньшее 544.

🔍 Копия и переворот записи: приём →

for N in range(1, 1000):
    R = f'{N:b}'
    if N % 4 == 0:
        R += R
    else:
        R += R[::-1]
    R = int(R, 2)
    if R >= 544:
        print(N)

Задача №7 ★ вставка в середину

📋 Полная формулировка

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится двоичная запись числа N.
  2. Далее эта запись обрабатывается по следующему правилу:
    а) если количество значащих цифр в двоичной записи числа чётное, то к этой записи в середину дописывается 1;
    б) если количество значащих цифр в двоичной записи числа нечётное, то запись не изменяется.
  3. Результат переводится в десятичную систему.

Например, для исходного числа 5₁₀ = 101₂ результат — 101₂ = 5₁₀, а для исходного числа 2₁₀ = 10₂ результат — 110₂ = 6₁₀.

Укажите минимальное число N, после обработки которого с помощью этого алгоритма получается число R, не меньше чем 26.

🔍 Вставка в середину: приём →

for N in range(1, 1000):
    R = f'{N:b}'
    if len(R) % 2 == 0:
        mid = len(R) // 2
        R = R[:mid] + '1' + R[mid:]
    R = int(R, 2)
    if R >= 26:
        print(N)
        break
Ответ: 12

Задача №8 ★ четверичная система

📋 Полная формулировка

На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.

  1. Строится четверичная запись числа N.
  2. Далее эта запись обрабатывается по следующему правилу:
    а) если число N делится на 4, то к этой записи дописываются две последние четверичные цифры;
    б) если число N на 4 не делится, то остаток от деления умножается на 2, переводится в четверичную запись и дописывается в конец числа.
  3. Результат переводится в десятичную систему.

Например, для исходного числа 11₁₀ = 23₄ результат — 2312₄ = 182₁₀, а для исходного числа 12₁₀ = 30₄ это число 3030₄ = 204₁₀.

Укажите максимальное число N, после обработки которого с помощью этого алгоритма получается число R, меньшее 261.

🔍 Четверичная система: пишем свою функцию to_quaternary() по аналогии с троичной. Собственная функция перевода →

def to_quaternary(num):
    result = ''
    while num:
        result += str(num % 4)
        num //= 4
    return result[::-1]

res = []
for N in range(1, 1000):
    R = to_quaternary(N)
    if N % 4 == 0:
        R += R[-2:]
    else:
        R += to_quaternary((N % 4) * 2)
    R = int(R, 4)
    if R < 261:
        res.append(N)

print(max(res))
Ответ: 61

Задача №9

📋 Полная формулировка

Автомат получает на вход трёхзначное число. По этому числу строится новое число по следующим правилам.

  1. Вычисляются суммы квадратов первой и второй, а также второй и третьей цифр исходного числа.
  2. Полученные два числа записываются друг за другом в порядке невозрастания (без разделителей).

Пример. Исходное число: 621. Суммы квадратов: 6² + 2² = 40; 2² + 1² = 5. Результат: 405.

Укажите наибольшее число, при обработке которого автомат выдаст число 9752.

for N in range(999, 99, -1):
    a, b, c = map(int, str(N))
    s1 = a**2 + b**2
    s2 = b**2 + c**2
    vals = sorted([s1, s2], reverse=True)
    R = str(vals[0]) + str(vals[1])
    if R == '9752':
        print(N)
        break
Ответ: 946

Задача №10

📋 Полная формулировка

Автомат получает на вход трёхзначное число. По этому числу строится новое число по следующим правилам.

  1. Перемножаются все цифры исходного числа.
  2. Суммируются все цифры исходного числа.
  3. Полученные два числа записываются друг за другом в порядке невозрастания (без разделителей).

Пример. Исходное число: 621. Произведение: 6×2×1 = 12; сумма: 6+2+1 = 9. Результат: 129.

Укажите наибольшее число, при обработке которого автомат выдаст число 33621.

for N in range(999, 99, -1):
    digits = [int(d) for d in str(N)]
    prod = digits[0] * digits[1] * digits[2]
    sum_d = digits[0] + digits[1] + digits[2]
    vals = sorted([prod, sum_d], reverse=True)
    R = str(vals[0]) + str(vals[1])
    if R == '33621':
        print(N)
        break
Ответ: 876

Задача №11

📋 Полная формулировка

Автомат получает на вход четырёхзначное число K. По этому числу строится новое число L по следующим правилам.

  1. Вычисляется S — сумма всех цифр числа K.
  2. Вычисляется M — максимальная цифра в записи числа K.
  3. Вычисляется N — минимальная цифра в записи числа K.
  4. Вычисляется P1 = S − M.
  5. Вычисляется P2 = S − N.
  6. L получается записью P1 и P2 в неубывающем порядке (без пробелов).

Пример. K = 6241. S = 13, M = 6, N = 1. P1 = 7, P2 = 12. Результат: L = 712.

Укажите наименьшее число K, при обработке которого автомат выдаст число L = 1318.

for K in range(1000, 10000):
    digits = [int(d) for d in str(K)]
    S = sum(digits)
    M = max(digits)
    N = min(digits)
    P1, P2 = S - M, S - N
    vals = sorted([P1, P2])
    L = str(vals[0]) + str(vals[1])
    if L == '1318':
        print(K)
        break
Ответ: 1666

Задача №12 ★ произведения пар

📋 Полная формулировка

Дано натуральное четырёхзначное число N. К нему применяется алгоритм.

  1. Перемножаются первая и вторая, вторая и третья, третья и четвёртая цифры числа.
  2. Полученные произведения записываются друг за другом в порядке неубывания.
  3. Незначащие нули в начале числа отбрасываются.

Например, для числа 1024: произведения — 0, 0, 8 → 008 → 8. Для числа 2311: произведения — 6, 3, 1 → 136.

Какое минимальное трёхзначное число можно получить?

res = []
for N in range(1000, 10000):
    a, b, c, d = [int(x) for x in str(N)]
    prods = [a*b, b*c, c*d]
    prods_sorted = ''.join(map(str, sorted(prods)))
    R = int(prods_sorted)
    if 100 <= R <= 999:
        res.append(R)

print(min(res))

💡 Отбрасывание незначащих нулей: int(prods_sorted) автоматически убирает ведущие нули. Например, int('008') → 8.

Ответ: 111
