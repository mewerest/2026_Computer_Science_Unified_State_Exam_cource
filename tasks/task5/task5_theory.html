Системы счисления

Система счисления — способ представления чисел с помощью определённого набора символов (цифр). Основание системы определяет, сколько различных цифр используется.

В задании 5 ЕГЭ используются четыре основные системы счисления:

  • Десятичная (основание 10) — цифры 0–9, повседневная система.
  • Двоичная (основание 2) — цифры 0 и 1, основа работы компьютеров.
  • Восьмеричная (основание 8) — цифры 0–7, одна цифра = 3 двоичных разряда.
  • Шестнадцатеричная (основание 16) — цифры 0–9 и буквы A–F, одна цифра = 4 двоичных разряда.

В общем случае для оснований больше 10 используются буквы латинского алфавита: A=10, B=11, ..., Z=35.

💡 Взаимосвязь систем: восьмеричная и шестнадцатеричная системы напрямую связаны с двоичной. Это позволяет быстро переводить числа между ними без вычислений.

Перевод чисел в различные системы счисления

Ручной метод

Перевод из десятичной системы в другие осуществляется методом последовательного деления на основание новой системы с записью остатков в обратном порядке.

1 Делим число на основание N, записываем остаток.

2 Частное снова делим на N, записываем следующий остаток.

3 Повторяем, пока частное не станет равно 0.

4 Читаем остатки снизу вверх — это и есть число в новой системе.

Пример: 42₁₀ → двоичная система

42 ÷ 2 = 21 (остаток 0)
21 ÷ 2 = 10 (остаток 1)
10 ÷ 2 = 5  (остаток 0)
5 ÷ 2 = 2   (остаток 1)
2 ÷ 2 = 1   (остаток 0)
1 ÷ 2 = 0   (остаток 1)
→ 101010₂

Перевод в Python

Python предоставляет несколько способов перевода чисел между системами счисления:

Направление Функция / метод Пример
Строка → десятичное int(строка, основание) int('101010', 2) → 42
Десятичное → двоичное bin(число) bin(42) → '0b101010'
Десятичное → восьмеричное oct(число) oct(42) → '0o52'
Десятичное → шестнадцатеричное hex(число) hex(42) → '0x2a'
Десятичное → любая (без префикса) format(число, 'b/o/x') format(42, 'b') → '101010'
Десятичное → любая (f-строка) f"{число:b/o/x}" f'{42:b}' → '101010'

💡 Совет: bin(), oct(), hex() добавляют префиксы 0b, 0o, 0x. Чтобы убрать префикс, используйте срез [2:] или format()/f-строки.

Собственная функция перевода (основания 2–36)

Для систем счисления, отличных от 2, 8, 16 (например, троичной, четверичной), в Python нет встроенных функций. Нужно написать свою — по тому же алгоритму последовательного деления.

Универсальная функция

from string import digits, ascii_uppercase

def convert(num, base):
    alph = digits + ascii_uppercase
    result = ''
    while num:
        result += alph[num % base]
        num //= base
    return result[::-1]

Как это работает: num % base даёт остаток — индекс символа в алфавите. num //= base уменьшает число. В конце переворачиваем строку — остатки записаны от последнего к первому.

🔍 Частный случай — троичная система: если в задаче всегда одна и та же система (например, троичная), можно упростить:

def to_ternary(num):
    result = ''
    while num:
        result += str(num % 3)
        num //= 3
    return result[::-1]

Типовые приёмы в задании 5

Замена символов в записи

В некоторых задачах нужно заменить все вхождения одного символа на другой (например, каждую «1» на «11»). Используем метод .replace():

# Замена каждой единицы на 11
R = R.replace('1', '11')

# Замена каждого нуля на 00
R = R.replace('0', '00')

Замена левых разрядов

Если нужно заменить два левых разряда на «11» или «10», используем срез: R = '11' + R[2:] — заменяем первые два символа на «11», остальное без изменений.

# Замена двух левых разрядов на 11
R = '11' + R[2:]

# Замена двух левых разрядов на 10
R = '10' + R[2:]

Вставка в середину строки

Если нужно вставить символ в середину двоичной записи: находим середину через len(R) // 2 и склеиваем три части.

# Вставка '1' в середину строки R
mid = len(R) // 2
R = R[:mid] + '1' + R[mid:]

Копия или переворот записи

Иногда нужно дописать справа саму запись (R += R) или её перевёрнутую версию (R += R[::-1]).

# Дописать справа саму запись
R += R

# Дописать справа перевёрнутую запись
R += R[::-1]

Подсчёт чётных цифр в записи

Часто в задании нужно определить, сколько чётных цифр в записи числа.

# Функция подсчёта чётных цифр в строке num (запись в системе base)
def count_evens(num, base):
    evens = sum([1 for d in num
                 if int(d, base) % 2 == 0])
    return evens

Сумма цифр в записи

# Сумма цифр строки R (любая система)
sum_d = sum(map(int, R))

map(int, R) применяет int() к каждому символу строки R, превращая его в число. sum() суммирует полученные числа.

Работа с цифрами десятичного числа

Отдельный класс задач в задании 5 — алгоритмы, работающие напрямую с десятичными цифрами исходного числа. Системы счисления здесь не используются.

Извлечение цифр числа

Самый простой способ получить все цифры числа — перевести его в строку: s = str(N). После этого с каждым символом можно работать как с отдельной цифрой, преобразуя обратно в число через int().

# Извлечение цифр числа N
s = str(N)
digits = [int(d) for d in s]

Операции с цифрами

Над извлечёнными цифрами можно выполнять любые операции: находить сумму, произведение, минимум, максимум, суммы квадратов, произведения пар и т.д.

digits = [int(d) for d in str(N)]

# Сумма цифр
s = sum(digits)

# Произведение цифр
p = 1
for d in digits:
    p *= d

# Максимальная и минимальная цифры
max_d = max(digits)
min_d = min(digits)

# Суммы квадратов соседних цифр (для трёхзначного числа)
a, b, c = digits
sum1 = a**2 + b**2
sum2 = b**2 + c**2

Составление результата из вычисленных значений

Результат обычно формируется склеиванием полученных чисел в порядке возрастания или убывания. Для сортировки используем sorted(), для склеивания — .join() или f-строки.

# Два числа: 40 и 5 → склеиваем в порядке невозрастания
result = str(40) + str(5)  # '405'

# Универсально: сортируем и склеиваем
vals = [40, 5]
vals_sorted = sorted(vals, reverse=True)  # по убыванию
result = ''.join(map(str, vals_sorted))  # '405'

💡 Незначащие нули: если в начале результата оказались нули, их нужно отбросить: result = result.lstrip('0') или result = str(int(result)).

Генератор двоичных чисел

Для работы с очень большими числами можно использовать генератор — он выдаёт значения по одному, не загружая память:

def bin_generator():
    n = 1
    while True:
        yield f'{n:b}'
        n += 1

💡 yield — ключевое слово, превращающее функцию в генератор. Вместо return (который завершает функцию) yield «замораживает» её состояние до следующего вызова. В ЕГЭ генераторы используются редко, но могут быть полезны.
