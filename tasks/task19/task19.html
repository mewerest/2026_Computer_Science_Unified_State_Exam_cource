1 куча ↑ 2 игрока Задача №1

📋 Полная формулировка (задания 19, 20, 21)

Два игрока, Петя и Ваня, играют в следующую игру. Перед игроками лежит куча камней. Игроки ходят по очереди, первый ход делает Петя. За один ход игрок может добавить в кучу один камень или увеличить количество камней в куче в два раза.

Игра завершается, когда количество камней в куче становится не менее 129. Победителем считается игрок, сделавший последний ход. В начальный момент в куче было S камней; 1 ≤ S ≤ 128.

Задание 19: укажите такое значение S, при котором Петя не может выиграть за один ход, но при любом ходе Пети Ваня может выиграть своим первым ходом.

Задание 20: найдите два наименьших значения S, при которых у Пети есть выигрышная стратегия, причём одновременно выполняются два условия: Петя не может выиграть за один ход; Петя может выиграть своим вторым ходом независимо от того, как будет ходить Ваня.

Задание 21: найдите минимальное значение S, при котором одновременно выполняются два условия: у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети; у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом.

📌 Тип: 1 куча → на увеличение → 2 игрока 
def f(s, m):
    if s >= 129:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s + 1, m - 1),
         f(s * 2, m - 1)]
    return any(h) if (m + 1) % 2 == 0 else all(h)

print('19:', *[s for s in range(1, 129) if f(s, 2)])
print('20:', *[s for s in range(1, 129) if f(s, 3) and not f(s, 1)])
print('21:', min([s for s in range(1, 129) if f(s, 4) and not f(s, 2)]))
Ответы:
19: 64
20: 56, 60
21: 55

1 куча ↓ 2 игрока Задача №3

📋 Полная формулировка (задания 19, 20, 21)

Два игрока, Петя и Ваня, играют в следующую игру. Перед игроками лежит куча камней. Игроки ходят по очереди, первый ход делает Петя. За один ход игрок может убрать из кучи 3 камня, убрать 8 камней или уменьшить количество камней в куче в 3 раза (с округлением до меньшего).

Игра завершается, когда количество камней в куче становится не более 16. Победителем считается игрок, сделавший последний ход. В начальный момент в куче было S камней; S ≥ 17.

Задание 19: укажите минимальное значение S, при котором Петя не может выиграть за один ход, но при любом ходе Пети Ваня может выиграть своим первым ходом.

Задание 21: найдите минимальное значение S, при котором одновременно выполняются два условия: у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети; у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом.

def f(s, m):

    if m == 0:

         f(s - 8, m - 1),
         f(s // 3, m - 1)]

print('19:', min([s for s in range(17, 100) if f(s, 2)]))

2 кучи ↑ 2 игрока Задача №4

📋 Полная формулировка (задания 19, 20, 21)

Два игрока, Петя и Ваня, играют в следующую игру. Перед игроками лежат две кучи камней. Игроки ходят по очереди, первый ход делает Петя. За один ход игрок может добавить в одну из куч один камень или увеличить количество камней в куче в два раза.

Игра завершается, когда суммарное количество камней в кучах становится не менее 77. Победителем считается игрок, сделавший последний ход. В начальный момент в первой куче было 7 камней, во второй — S камней; 1 ≤ S ≤ 69.

Известно, что Ваня выиграл своим первым ходом после неудачного хода Пети.

Задание 19: укажите минимальное значение S, когда такая ситуация возможна.

Задание 20: найдите два таких значения S, при которых у Пети есть выигрышная стратегия, причём одновременно выполняются два условия: Петя не может выиграть за один ход; Петя может выиграть своим вторым ходом независимо от того, как будет ходить Ваня.

Задание 21: найдите минимальное значение S, при котором одновременно выполняются два условия: у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети; у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом.

📌 Тип: 2 кучи → на увеличение → 2 игрока 
def f(s1, s2, m):
    if s1 + s2 >= 77:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s1 + 1, s2, m - 1),
         f(s1, s2 + 1, m - 1),
         f(s1 * 2, s2, m - 1),
         f(s1, s2 * 2, m - 1)]
    # Для 19 — только any (Петя сходил неудачно)
    # return any(h)
    return any(h) if (m + 1) % 2 == 0 else all(h)

# Для 19 раскомментировать return any(h) и использовать:
# print('19:', min([s for s in range(1, 70) if f(7, s, 2)]))

print('20:', *[s for s in range(1, 70) if f(7, s, 3) and not f(7, s, 1)])
print('21:', min([s for s in range(1, 70) if f(7, s, 4) and not f(7, s, 2)]))

💡 Для задания 19: фраза «после неудачного хода Пети» означает, что Петя ошибся и дал Ване возможность выиграть. Поэтому не нужно проверять, что все ходы Пети ведут к победе Вани — достаточно, что существует хотя бы один такой ход. В коде это return any(h) вместо any/all.

Ответы:
19: 17
20: 33, 36
21: 32

3 кучи ↑ 2 игрока Задача №5

📋 Полная формулировка (задания 19, 20, 21)

Два игрока, Петя и Ваня, играют в следующую игру. Перед ними лежат три кучки камней, в первой из которых 2, во второй – 3, в третьей – S (1 ≤ S ≤ 19) камней. У каждого игрока неограниченное количество камней. Игроки ходят по очереди, первый ход делает Петя. Ход состоит в том, что игрок или удваивает число камней в какой-то куче, или добавляет по два камня в каждую из куч.

Выигрывает игрок, после хода которого в одной из куч становится не менее 20 камней, или после хода которого общее число камней во всех трёх кучах становится не менее 25.

Задание 19: укажите такое значение S, при котором Петя не может выиграть за один ход, но при любом ходе Пети Ваня может выиграть своим первым ходом.

Задание 20: найдите два наименьших значения S, при которых у Пети есть выигрышная стратегия, причём одновременно выполняются два условия: Петя не может выиграть за один ход; Петя может выиграть своим вторым ходом независимо от того, как будет ходить Ваня.

Задание 21: найдите минимальное значение S, при котором одновременно выполняются два условия: у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети; у Вани нет стратегии, которая позволит ему гарантированно выиграть первым ходом.

📌 Тип: 3 кучи → на увеличение → 2 игрока

🔍 Особенности задачи с тремя кучами:

  • Функция принимает три аргумента: f(s1, s2, s3, m)
  • Условие победы: s1 >= 20 or s2 >= 20 or s3 >= 20 or s1+s2+s3 >= 25
  • Локальные операции: удвоение каждой из трёх куч
  • Глобальная операция: добавить по 2 камня в каждую кучу

Подробнее о задачах с тремя кучами — в теории →

def f(s1, s2, s3, m):
    if s1 >= 20 or s2 >= 20 or s3 >= 20 or s1 + s2 + s3 >= 25:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s1 * 2, s2, s3, m - 1),
         f(s1, s2 * 2, s3, m - 1),
         f(s1, s2, s3 * 2, m - 1),
         f(s1 + 2, s2 + 2, s3 + 2, m - 1)]
    return any(h) if (m + 1) % 2 == 0 else all(h)

# Начальное состояние: [2, 3, S]
print('19:', *[s for s in range(1, 20) if f(2, 3, s, 2)])
print('20:', *[s for s in range(1, 20) if f(2, 3, s, 3) and not f(2, 3, s, 1)])
print('21:', min([s for s in range(1, 20) if f(2, 3, s, 4) and not f(2, 3, s, 2)]))
Ответы:
19: 8
20: 10, 11
21: 9

1 куча ↑ 3 игрока (коалиция) Задача №6

📋 Полная формулировка (задания 19, 20, 21)

Три игрока, Петя, Ваня и Екатерина, играют в следующую игру. Перед игроками лежит куча камней. Игроки ходят по очереди, первый ход делает Екатерина, второй – Петя, третий – Ваня. За один ход игрок может добавить в кучу один камень или увеличить количество камней в куче в два раза.

Игра завершается, когда количество камней в куче становится не менее 30. Победителем считается игрок, сделавший последний ход. В начальный момент в куче было S камней; 1 ≤ S ≤ 29.

Задание 19: Известно, что Ваня выиграл своим первым ходом. При каком минимальном значении S это возможно?

Задание 20: Екатерина и Ваня сговорились. Они хотят, чтобы Петя не выиграл. Найдите минимальное значение S, при котором у них гарантированно получится играть так, чтобы Петя не смог выиграть.

Задание 21: Екатерина и Петя сговорились. Они хотят, чтобы Екатерина победила своим вторым ходом. Сколько существует значений S, при которых Екатерина и Петя гарантированно смогут осуществить их план?

📌 Тип: 1 куча → на увеличение → 3 игрока (кооперативная)

🔍 Особенности кооперативных задач с тремя игроками:

  • Игроки ходят по очереди: Екатерина (ход 0) → Петя (ход 1) → Ваня (ход 2) → ...
  • В задании 19: нужно проверить, что существует ход Пети, после которого Ваня может выиграть.
  • В задании 20: коалиция Екатерина+Ваня против Пети. Ходы Екатерины и Вани — any(), ход Пети — all().
  • В задании 21: коалиция Екатерина+Петя. Цель — победа Екатерины на втором ходу.

Подробнее о коалиционных играх — в теории →

# Коалиция: Екатерина + Ваня против Пети
# Екатерина (m % 3 == 0), Петя (m % 3 == 1), Ваня (m % 3 == 2)

def f(s, m):
    if s >= 30:
        # Для задания 19: Ваня выиграл → m % 3 == 2
        # return m % 3 == 2
        # Для заданий 20-21: коалиция выиграла → не Петя
        return m % 3 != 1
    if m == 0:
        return False
    h = [f(s + 1, m - 1),
         f(s * 2, m - 1)]
    # Если ход Пети (противника) — all()
    # Если ход союзника — any()
    return all(h) if m % 3 == 1 else any(h)

# Задание 19: Ваня выиграл своим первым ходом
# В f(s, m) заменить return на m % 3 == 2
# print('19:', min([s for s in range(1, 30) if f(s, 2)]))

# Задание 20: Екатерина + Ваня против Пети
print('20:', min([s for s in range(1, 30) if f(s, 3)]))

# Задание 21: Екатерина + Петя, Екатерина побеждает вторым ходом
# Екатерина ходит на 0-м и 3-м ходу (m = 3 — второй ход Екатерины)
# В f(s, m) заменить return на m % 3 == 0 (Екатерина выиграла)
# Искать: f(s, 3) and f(s, 2) — Екатерина выигрывает на втором ходе
# print('21:', len([s for s in range(1, 30) if f(s, 3) and not f(s, 2)]))

💡 Важно: для задания 19 нужно заменить условие победы на return m % 3 == 2 (Ваня выиграл). Для задания 21 — на return m % 3 == 0 (Екатерина выиграла). Логика any()/all() остаётся той же.

Ответы:
19: 16
20: 15
21: 4
