Методы решения задач 19–21

Задачи 19–21 можно решать тремя способами. Каждый имеет свои преимущества и недостатки.

Метод 1: Аналитический (ручной)

Суть: анализ игры с конца (от целевого значения к начальному). Строится дерево решений, выделяются выигрышные и проигрышные позиции.

Когда использовать: для небольших диапазонов S (до 30–40) и простых правил.

Плюсы: развивает логическое мышление, не требует компьютера.

Минусы: трудоёмко для больших диапазонов и сложных правил.

Метод 2: Программный (рекурсивная функция)

Суть: пишется рекурсивная функция, которая перебирает все возможные ходы и определяет выигрышные стратегии.

Когда использовать: для любых задач — универсальный метод.

Плюсы: надёжен, легко проверяется, работает для любых диапазонов.

Минусы: требует навыков программирования.

# Базовый шаблон для 1 кучи (на увеличение)
def f(s, m):
    if s >= цель:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(ход1, m-1), f(ход2, m-1), ...]
    return any(h) if (m+1) % 2 == 0 else all(h)

Метод 3: Электронные таблицы (Excel / Google Sheets)

Суть: строится таблица, где строки — возможные значения S, столбцы — ходы. Ячейки заполняются по рекуррентной формуле.

Когда использовать: если нет доступа к Python или нужно быстро проверить гипотезу.

Плюсы: наглядно, не требует программирования.

Минусы: трудоёмко для больших таблиц, сложно автоматизировать поиск.

💡 Рекомендация: на экзамене используйте программный метод — он надёжен и универсален. Аналитический метод полезен для понимания логики игры. Электронные таблицы — для быстрой проверки.

Базовый алгоритм для 2 игроков

Для классических задач с двумя игроками (Петя и Ваня) используется единый шаблон рекурсивной функции.

Логика проверки

1 Если достигнуто целевое состояние — проверяем, чей это ход. Побеждает тот, на чьём ходу достигнута цель.

2 Если m = 0 — ходы закончились, а цель не достигнута → поражение.

3 Формируем список h — результаты всех возможных ходов.

4 Если ход чётный (Ваня) — нужно, чтобы хотя бы один вариант вёл к победе → any(h).

5 Если ход нечётный (Петя) — нужно, чтобы все варианты вели к победе → all(h).

Три кучи

Задачи с тремя кучами — игры, где есть три независимые кучи камней. Игроки могут изменять одну из куч или все кучи одновременно.

Особенности задач с тремя кучами:

  • Функция принимает три аргумента: f(s1, s2, s3, m).
  • Условие победы может быть сложным: например, «в одной из куч ≥ 20 ИЛИ суммарно ≥ 25».
  • Операции могут быть двух видов:
    • Локальные: изменяют одну кучу (удвоить камни в какой-то куче).
    • Глобальные: изменяют все кучи (добавить по 2 камня в каждую).

Шаблон для трёх куч

def f(s1, s2, s3, m):
    # Условие победы (может быть сложным)
    if s1 >= 20 or s2 >= 20 or s3 >= 20 or s1 + s2 + s3 >= 25:
        return m % 2 == 0
    if m == 0:
        return False
    
    # Локальные операции (изменяют одну кучу)
    h = [f(s1 * 2, s2, s3, m-1),  # удвоить первую
         f(s1, s2 * 2, s3, m-1),  # удвоить вторую
         f(s1, s2, s3 * 2, m-1),  # удвоить третью
         f(s1 + 2, s2 + 2, s3 + 2, m-1)]  # глобальная операция
    
    return any(h) if (m+1) % 2 == 0 else all(h)

⚠️ Важно: в задачах с тремя кучами начальное состояние может быть фиксированным для двух куч и переменным для третьей. Например: [2, 3, S]. В этом случае в поиске перебирается только S.

Три игрока и коалиции

Кооперативная игра — игра, в которой игроки могут объединяться в коалиции для достижения общей цели. В заданиях 19–21 это обычно «сговор» двух игроков против третьего.

В задачах с тремя игроками (например, Екатерина, Петя, Ваня) появляются новые типы вопросов:

  • Задание 19: «Ваня выиграл своим первым ходом» — нужно проверить, что существует ход Пети, после которого Ваня может выиграть.
  • Задание 20: «Екатерина и Ваня сговорились, чтобы Петя не выиграл» — коалиция Екатерина+Ваня против Пети.
  • Задание 21: «Екатерина и Петя сговорились, чтобы Екатерина выиграла своим вторым ходом» — коалиция Екатерина+Петя.

Особенности анализа коалиций

В кооперативных играх логика any() / all() меняется в зависимости от того, кто делает ход и кто должен выиграть:

  • Ход игрока, входящего в коалицию: он будет выбирать ход, который помогает достичь цели коалиции → any() (ему достаточно одного хорошего хода).
  • Ход игрока, НЕ входящего в коалицию (противника): он будет пытаться помешать → all() (коалиция должна быть готова к любому его ходу).

Шаблон для трёх игроков

# Коалиция: Екатерина + Ваня против Пети
# Екатерина ходит первой, Петя второй, Ваня третий

def f(s, m):
    if s >= 30:
        # Побеждает игрок, сделавший последний ход
        # m % 3 == 0 — Екатерина, == 1 — Петя, == 2 — Ваня
        return m % 3 == 2  # Ваня выиграл
    if m == 0:
        return False
    
    h = [f(s + 1, m-1), f(s * 2, m-1)]
    
    # Кто сейчас ходит?
    # m % 3 == 0 — Екатерина (в коалиции) → any()
    # m % 3 == 1 — Петя (противник) → all()
    # m % 3 == 2 — Ваня (в коалиции) → any()
    
    if m % 3 == 1:  # Ход Пети — противник
        return all(h)
    return any(h)  # Екатерина или Ваня — коалиция

💡 Ключевые отличия от 2 игроков:

  • Нужно отслеживать, чей сейчас ход (m % 3).
  • Логика any() / all() зависит от принадлежности игрока к коалиции.
  • В условии победы нужно проверять, кто выиграл (m % 3).

Различие заданий 19, 20 и 21

ЗаданиеЧто требуетсяФормула (для 2 игроков)
19Петя не может выиграть за 1 ход, но Ваня выигрывает первым ходомf(s, 2)
20Петя не может выиграть за 1 ход, но выигрывает вторым ходомf(s, 3) and not f(s, 1)
21Ваня выигрывает первым или вторым ходом, но не гарантированно первымf(s, 4) and not f(s, 2)

🔍 Для 3 игроков: задания формулируются иначе, но суть та же — анализ выигрышных стратегий для конкретных игроков или коалиций на определённых ходах.

📖 Программные шаблоны

Шаблоны кода для разных типов задач

Шаблон 1: 1 куча, на увеличение, 2 игрока

def f(s, m):
    if s >= цель:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s + a, m-1), f(s * b, m-1), ...]
    return any(h) if (m+1) % 2 == 0 else all(h)

Шаблон 2: 1 куча, на уменьшение, 2 игрока

def f(s, m):
    if s <= цель:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s - a, m-1), f(s // b, m-1), ...]
    return any(h) if (m+1) % 2 == 0 else all(h)

Шаблон 3: 2 кучи, 2 игрока

def f(s1, s2, m):
    if s1 + s2 >= цель:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s1 + a, s2, m-1),
         f(s1, s2 + a, m-1),
         f(s1 * b, s2, m-1),
         f(s1, s2 * b, m-1)]
    return any(h) if (m+1) % 2 == 0 else all(h)

Шаблон 4: 3 кучи, 2 игрока

def f(s1, s2, s3, m):
    if s1 >= a or s2 >= a or s3 >= a or s1+s2+s3 >= b:
        return m % 2 == 0
    if m == 0:
        return False
    h = [f(s1 * 2, s2, s3, m-1),
         f(s1, s2 * 2, s3, m-1),
         f(s1, s2, s3 * 2, m-1),
         f(s1 + c, s2 + c, s3 + c, m-1)]
    return any(h) if (m+1) % 2 == 0 else all(h)

Шаблон 5: 3 игрока, коалиция (на примере Задачи №6)

# Коалиция Екатерина + Ваня против Пети
# Екатерина (ход 0), Петя (ход 1), Ваня (ход 2)
def f(s, m):
    if s >= 30:
        # Проверяем, выиграл ли игрок из коалиции
        return m % 3 != 1  # Не Петя
    if m == 0:
        return False
    h = [f(s + 1, m-1), f(s * 2, m-1)]
    # Если ход Пети (противника) — all()
    return all(h) if m % 3 == 1 else any(h)

💡 Важно: для коалиционных задач логика any() / all() зависит от того, чей сейчас ход и кто входит в коалицию. Противник использует all(), союзники — any().
