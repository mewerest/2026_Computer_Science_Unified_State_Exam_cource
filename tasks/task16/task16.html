О задании

Задание 16 проверяет умение работать с рекурсивными алгоритмами. Дана функция, заданная соотношениями. Нужно вычислить значение выражения, содержащего вызовы этой функции. Для решения используются: ручной метод, обычная рекурсия (при глубине > 1000 — с sys.setrecursionlimit()), итеративный подход и мемоизация через @lru_cache.

Ручное решение

Для небольшой глубины рекурсии проще всего решить вручную — подставить значения и сократить выражение. Никакого кода не требуется.

Задача №1

📋 Полная формулировка

Тело функции F(n) задано следующими строчками и условиями:
F(n) = 1, при n < 2,
F(n) = F(n−1) × (n+5), при n ≥ 2.
При этом n — натуральное число. Определите, что вернёт данная функция, если в неё передать аргумент n = 5.

1 F(1) = 1 (базовый случай).

2 F(2) = F(1) × (2+5) = 1 × 7 = 7.

3 F(3) = F(2) × (3+5) = 7 × 8 = 56.

4 F(4) = F(3) × (4+5) = 56 × 9 = 504.

5 F(5) = F(4) × (5+5) = 504 × 10 = 5040.

Ответ: 5040

Обычная рекурсия

Для большинства задач 16 достаточно просто переписать функцию из условия и вызвать её. Глубина рекурсии здесь не превышает 1000.

Задача №2

📋 Полная формулировка

Алгоритм вычисления значения функции F(n), где n — целое неотрицательное число, задан следующими соотношениями:
F(0) = 0,
F(n) = F(n/2), если n > 0 и при этом n чётно,
F(n) = 1 + F(n−1), если n > 0 и при этом n нечётно.
Назовите минимальное значение n, для которого F(n) = 12.

def F(n):
    if n == 0:
        return 0
    if n % 2 == 0:
        return F(n // 2)
    return 1 + F(n - 1)

n = 1
while F(n) != 12:
    n += 1
print(n)
Ответ: 4095

Задача №3

📋 Полная формулировка

Алгоритм вычисления значения функции F(n), где n — натуральное число, задан следующими соотношениями:
F(n) = 1, если n = 1,
F(n) = n × F(n−1), если n > 1.
Чему равно значение выражения F(2222) / F(2219)?

# Это факториал: F(n) = n!
# F(2222) / F(2219) = 2222! / 2219! = 2222 × 2221 × 2220
print(2222 * 2221 * 2220)

💡 Совет: если функция сводится к факториалу, не нужно писать рекурсию — сократите дробь аналитически.

Рекурсия с увеличением глубины

Когда аргумент превышает 1000, стандартной глубины рекурсии не хватает. Добавляем sys.setrecursionlimit(3000) перед вызовом функции.

Задача №4

📋 Полная формулировка

Тело функции F(n) задано следующими строчками:
F(n) = 1, если n = 1,
F(n) = (3×n + 6) × F(n−1), если n > 1.
Чему равно значение выражения F(2345) / F(2343)?

import sys
sys.setrecursionlimit(3000)

def F(n):
    if n == 1:
        return 1
    return (3 * n + 6) * F(n - 1)

print(F(2345) // F(2343))

💡 Можно и без рекурсии: F(2345) / F(2343) = (3×2345+6) × (3×2344+6). Но здесь показан общий подход с рекурсией.

Ответ: 49554558

Задача №5

📋 Полная формулировка

Тело функции F(n) задано следующими строчками:
F(n) = n, если n ≥ 2025,
F(n) = n + F(n+2), если n < 2025.
Чему равно значение выражения F(2020) − F(2023)?

import sys
sys.setrecursionlimit(3000)

def F(n):
    if n >= 2025:
        return n
    return n + F(n + 2)

print(F(2020) - F(2023))

💡 Это рекурсия «вверх»: аргумент растёт (n → n+2), базовый случай при n ≥ 2025. Подробнее в теории →

Ответ: 4044

Задача №6

📋 Полная формулировка

Тело функций F(n) и G(n) задано следующими строчками, где n — целое неотрицательное число:
F(1) = 1,
F(n) = 2 × G(n) + 3 × n, при n > 1,
G(1) = 1,
G(n) = F(n−1) + 5 × n, при n > 1.
Чему равно значение модуля разности функции F(4) − G(5)? В ответе запишите только натуральное число.

import sys
sys.setrecursionlimit(3000)

def F(n):
    if n == 1:
        return 1
    return 2 * G(n) + 3 * n

def G(n):
    if n == 1:
        return 1
    return F(n - 1) + 5 * n

print(abs(F(4) - G(5)))
Ответ: 25

Итеративный подход

Когда формула сложная и содержит целую часть от деления, итеративный подход (список + цикл) часто проще и надёжнее рекурсии. Подробнее в теории →

Задача №7

📋 Полная формулировка

Пусть [x] — это целая часть числа x, а / — обычное, нецелочисленное деление. Функция F(n) задана следующими строчками и условиями:
F(0) = 0,
F(1) = 1,
F(n) = 2 + [3×F(n−1)/3], при чётном n и n > 1,
F(n) = 2×n + [(F(n−1) + F(n−3) + 2) / 3], при нечётном n и n > 1.
При этом n — целое неотрицательное число. Определите, какое значение вернёт данная функция F(), если в неё передать аргумент n = 30.

def F_iter(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    cache = [0, 1]  # F(0), F(1)
    for i in range(2, n + 1):
        if i % 2 == 0:
            cache.append(2 + int(3 * cache[i - 1] / 3))
        else:
            cache.append(2 * i + int((cache[i - 1] + cache[i - 3] + 2) / 3))
    return cache[n]

print(F_iter(30))

💡 Целая часть от деления в Python — int(x / y) или x // y. Здесь используется int(...) для соответствия записи [x] в условии.

Ответ: 146

Перебор на отрезке с мемоизацией

Нужно не просто вычислить одно значение, а перебрать отрезок и подсчитать количество n с заданным свойством. Мемоизация через @lru_cache с прогревом кеша позволяет сделать это эффективно.

Задача №8

📋 Полная формулировка

Алгоритм вычисления значения функции F(n), где n — целое неотрицательное число, задан следующими соотношениями:
F(0) = 5,
F(n) = 1 + F(n/2), когда n > 0 и n чётное,
F(n) = F(n/2), когда n > 0 и n нечётное.
Здесь / означает деление нацело. Определите количество значений n на отрезке [1; 1000], для которых F(n) = 7.

from functools import lru_cache

@lru_cache()
def F(n):
    if n == 0:
        return 5
    if n % 2 == 0:
        return 1 + F(n // 2)
    return F(n // 2)

# Прогреваем кеш для всех n от 0 до 1000
for i in range(1001):
    F(i)

# Считаем количество n на [1; 1000], для которых F(n) = 7
count = sum(1 for i in range(1, 1001) if F(i) == 7)
print(count)
Ответ: 111
